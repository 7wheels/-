# _참고자료

히어컴퍼니 (HearCompany) 기업컨설팅 하네스에서 **모든 클라이언트에 공통 참조**되는 공용 문서·자료 보관함.

## 보관 대상

- 벤처기업확인제도 가이드북 (예: `벤처기업확인제도_가이드북_YYYYMM.pdf`)
- 정부지원사업 가이드·심사 매뉴얼
- NCS 직무 표준 문서
- 정책자금·보증재단 신청서 양식
- 산업·시장 통계 자료 (중소기업전략기술로드맵 등)
- 기타 클라이언트 무관 공용 참조 자료

## 사용 규칙

- 클라이언트별 자료는 `{기업명}/_참고자료/`에 분리 보관
- 본 폴더는 공용 자료만 — 클라이언트 식별 정보·기밀 자료 금지
- 파일명에 발행 연·월 명기 권장 (`_YYYYMM` 접미)
- 대용량 PDF는 GitHub Web UI로 업로드 후, Read 도구의 `pages` 파라미터로 분할 분석
