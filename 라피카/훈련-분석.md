## 2. 5인 미만 소기업 환급 우대

라피카는 **우선지원대상기업(소기업·5인 미만)**으로 다음 우대 적용:

| 항목 | 일반 기업 | 우선지원대상 (라피카) |
|------|---------|---------------------|
| 집체훈련 환급률 | 60% | **100%** |
| 원격훈련 환급률 | 50% | **100%** |
| S-OJT 훈련수당 | — | **트레이너 시간당 수당 지급 인정** |
| 1인당 연 한도 | 일반 한도 | 우선지원 한도(상향) 적용 |

## 3. 환급 시뮬레이션 (보수적 추정)

### 시나리오 A — 기본형 (S-OJT 1과정 / 40시간)
```
훈련 인원: 2명
훈련 시간: 40시간/인
표준훈련비 인정 단가: 약 8,000원/시간 (NCS 17 화학 기준)
훈련생 임금 보전: 시간당 최저임금 × 100%

총 인정금액(추정):
  - 훈련비: 40h × 2명 × 8,000원 = 640,000원
  - 임금 보전: 40h × 2명 × 9,860원 = 788,800원
  - 트레이너 수당(내부): 40h × 12,000원 = 480,000원
  ─────────────────────────────────────────
  합계: 약 1,900,000원 환급 가능
```

### 시나리오 B — 권장형 (S-OJT 2과정 + 원격 1과정 / 연간)
```
훈련 구성:
  - S-OJT 핵심 직무 1: 40h × 2명
  - S-OJT 핵심 직무 2: 30h × 2명
  - 원격 NCS 보완 과정: 20h × 2명

연간 환급 추정: 약 4,500,000~6,000,000원
```

### 시나리오 C — 최대화형 (인원 보강 후 / 5명 기준)
```
신규 인력 채용 + 컨소시엄 훈련 가입 시
연간 환급 추정: 약 12,000,000~18,000,000원
+ 정부지원사업 인력 양성 사업 별도 매칭 시 추가
```

> ⚠️ 위 단가는 2026년 고용노동부 고시 기준 추정치이며,
> 실제 환급액은 HRD-Net 승인 시 확정된다.

## 5. S-OJT 에이전트로의 전달 사항

- 훈련 대상: 2명 (대표 포함 가능, 사전 확인 필요)
- 트레이너: 외부 강사 활용 가능, 내부 양성 병행 권장
- NCS 분류: 화장품은 **17 화학** 우선, 영업·PM·무역은 **02 경영·회계·사무**
- 우선지원대상 기준 환급률 적용

## 6. 인증 에이전트와의 연결고리 (선제 제안)

- ISO 22716(화장품 GMP) 인증 추진 시 → 품질 직무 S-OJT 계획서가 인증 심사
  교육훈련 기록의 근거 문서로 활용 가능
- 기업부설연구소 설립 시 → 연구인력 인건비 세액공제 + S-OJT 환급
  이중 활용 가능 (단, 동일 시간 중복 인정 불가)
