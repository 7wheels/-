| 항목 | 내용 |
|------|------|
| 기업명 | (주)라피카 |
| 업종 | **화장품 OEM 제조업** (기존 "제조·도소매" → OEM으로 재정의) |
| 규모 | 직원 2명 / 연매출 3억 / 4년차 (2022년 설립) |

**OEM 제조업 특화 진단:**
- 직원 2명 초소기업이라 직무 1인 다역 구조 → S-OJT로 핵심 직무 표준화 필수
- 화장품책임판매업·제조업 등록 기업이면 **CGMP·ISO 22716** 대비 훈련 가치 높음
- OEM 영업·PM 직무는 고객 처방 제안 역량이 매출 직결 → 별도 과정 필요
- 수출(K-뷰티) 확장 시 **글로벌 인허가(CPNP·FDA·NMPA)** 실무가 병목

## 갱신 (2026-05-04, 사용자 추가 정보 반영)

**제약 조건 추가:**
1. 작년에 **품질관리(QC) 과정 이미 실시** → ② 과정 제외 (중복 회피)
2. **실험·연구장비 없음** → ① R&D 처방개발 과정 제외 (실습 불가)
3. 공단(인적자원개발위/지방고용노동청) **"생산성 정량 지표"** 요구
4. 방향: **OEM 생산관리** + 생산성 KPI 강조

**의사결정:**
- 5선 중 ①②는 제외 / ③④⑤는 직무 영역이 다름 (생산관리 부재)
- → **신규 ⑥ "화장품 OEM 생산관리 및 생산성 향상 실무 과정"** 단일안 권고
- 생산성 측정 가능 단원으로 평가기준 10개를 구성하여 심사 대응력 강화

**S-OJT에게 재지시:**
- 추천 5선을 폐기하지 말고 "갱신 권고안" 섹션을 추가하여 ⑥ 단일안 제시
- 사용자 confirm 후 Phase 2(3묶음 커리큘럼) 진행
- 실습 60%를 실험이 아닌 **현장 측정·기록·분석 활동**으로 구성
  (스톱워치 표준시간 측정 / 라인 가동률 계산 / 불량 원인 분석 /
   일일 생산일보 작성 / 자재 수율 산출 등)

## 확정 (2026-05-04)
