# 기업인증 취득 로드맵

## 인증 포트폴리오 설계 원칙

인증은 순서가 중요하다. 앞 인증이 뒤 인증의 요건 충족에 도움이 되도록 순서를 설계한다.

## 표준 인증 취득 순서

```
기업부설연구소 설립
    ↓ (연구인력·과제 확보)
벤처기업 확인 (연구개발형)
    ↓ (기술혁신 실적 누적)
이노비즈 인증
    ↓ (경영혁신 추가)
메인비즈 인증 (선택)
    ↓
ISO 인증 (품질·환경)
```

---

## 인증별 상세 로드맵

### 1. 기업부설연구소

**요건 (제조업 기준):**
- 연구전담요원: 3인 이상 (석사 또는 학사 3년 이상)
- 연구 공간: 독립된 전용 공간 (칸막이 이상)
- 연구 과제: 자체 R&D 과제 보유

**설립 혜택:**
- 연구인력 인건비 25% 세액공제 (중소기업)
- 연구개발비 25% 세액공제
- 기술금융 우대

**준비 기간:** 1-3개월

---

### 2. 벤처기업 확인

**유형별 요건:**

| 유형 | 요건 |
|------|------|
| 벤처투자형 | VC 투자 5천만원 이상 |
| 연구개발형 | 연매출 5% 이상 R&D 지출 + 기업부설연구소 |
| 혁신성장형 | 기보 또는 중진공 보증 1억 이상 + 기술평가 우수 |

**혜택:**
- 코스닥 상장 특례 (기술특례상장)
- 취득세·재산세 감면
- 정책자금 우대 (기보 0.5% 보증료)

**유효기간:** 2년 (갱신 필요)

---

### 3. 이노비즈 (INNO-BIZ)

**요건:**
- 업력 3년 이상 중소기업
- 기술혁신 시스템 평가 700점 이상/1000점

**평가 항목:**
- 기술역량 (30%), 기술사업화 (30%)
- 기술경영역량 (20%), 기술혁신성과 (20%)

**혜택:**
- 중진공 정책자금 우대금리
- 공공조달 우선구매 및 가점
- 기보 보증료 0.5% (벤처기업 수준)

**준비 기간:** 3-6개월 (내부 시스템 정비 필요)

---

### 4. 메인비즈 (MAIN-BIZ)

**요건:**
- 경영혁신 시스템 평가 700점 이상

**평가 항목:**
- 전략적 혁신 (35%), 공정 혁신 (25%)
- 관리 혁신 (20%), 혁신 성과 (20%)

**혜택:**
- 이노비즈와 유사한 정책자금 우대
- 경영 혁신 분야 추가 지원

---

### 5. ISO 인증

**ISO 9001 (품질경영):**
- 준비 기간: 3-6개월
- 비용: 심사비용 약 200-400만원
- 필수 조건: 조달청 입찰, 일부 대기업 협력사 등록

**ISO 14001 (환경경영):**
- 제조업·화학업종 필수
- ESG 경영 기반

## 기업 유형별 추천 인증 경로

### 제조 기업
```
기업부설연구소 → 벤처(연구개발형) → 이노비즈 → ISO 9001
예상 기간: 12-18개월
```

### IT·소프트웨어 기업
```
벤처(혁신성장형) → 기업부설연구소 → 이노비즈 → ISO 27001
예상 기간: 6-12개월
```

### 서비스 기업
```
벤처(혁신성장형) → 메인비즈 → 이노비즈
예상 기간: 6-12개월
```

### 스타트업 (창업 3년 이내)
```
벤처(벤처투자형 or 혁신성장형) → 기업부설연구소
예상 기간: 3-6개월
```

## 인증별 세액공제 효과 계산

### 예시: 연매출 30억, 연구인력 3명 (각 연봉 5천만원)

| 항목 | 세액공제액 |
|------|---------|
| 연구인력 인건비 (1.5억 × 25%) | 3,750만원 |
| 연구개발비 (매출 5% = 1.5억 × 25%) | 3,750만원 |
| 합계 | **7,500만원** |

→ 기업부설연구소 설립만으로 연 7,500만원 절세 효과
