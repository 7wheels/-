# 천창성 — 영성 생태계 프로파일

> 에이전트 팀 공통 참조 파일. 모든 콘텐츠 생성 시 이 맥락을 기반으로 한다.

## 신학 여정

| 단계 | 내용 |
|------|------|
| 출발 | 제칠일안식일예수재림교(SDA) 목사 |
| 탐구 | 명상·마음공부·끌어당김·자기개발 심취 |
| 전환점 | 마이클 싱어(Untethered Soul) — 내면 목격자 영성 발견 |
| 신학 정착 | 앤드류 워맥 — 은혜·정체성·그리스도 내주 신학 |
| 통합 | 네빌 고다드(I AM 의식) + 나폴레옹 힐(신념·목적) |
| 현재 비전 | 위를 통합한 기독교 기반 신앙공동체 + 교육·콘텐츠 생태계 |

## 핵심 신학 포지션

- **정체성의 기초**: 갈 2:20 — 내 안에 사시는 그리스도
- **은혜 신학**: 워맥 — 이미 완성된 구속, 행위 아닌 수용
- **I AM**: 출 3:14의 하나님 이름 → 그리스도와 연합한 자의 정체성 선언
- **안식일**: 히 4:9-11 — 토요일 규례가 아닌 그리스도 안의 완성된 안식
- **끌어당김 재번역**: 우주가 아닌 언약의 하나님 / 끌어당김이 아닌 알아차림

## 통합 신학 중심문장

> "그리스도께서 내 안에 사신다 — 나는 비움으로 사랑이 되고, 안식으로 창조하며, 내어드림으로 자유롭다."
> — 갈 2:20 + 골 1:27 + 히 4:9

## 공동체 비전: 내주(內住) / INDWELLING

- **타깃**: 교회 떠났지만 하나님 못 버린 사람 / 자기계발에 지친 사람 / 열심히 믿는데 변화 없는 사람
- **채널**: 유튜브(INDWELLING) + 뉴스레터(주2회, 100회) + 30주 교육과정 + 오프라인 리트릿

## 교육 자산 (지식 베이스)

- 워맥 동영상 요약 슬라이드 → `knowledge-base/` 카테고리별 저장
- 신학 연구 노트 → `knowledge-base/` 에 통합
- 생성된 강의·뉴스레터 → `content-library/` 에 저장

## 콘텐츠 생성 원칙

1. 워맥의 언어와 성경 본문을 먼저 기반으로 삼는다
2. 끌어당김·명상 등 세속 언어는 반드시 성경 언어로 재번역하여 사용
3. 자기계발에서 온 독자도 이해할 수 있는 접근성 유지
4. 모든 I AM 선언은 "그리스도와의 연합" 맥락을 명시
5. 참 안식일은 히브리서 4장 기반, SDA 율법주의와 명확히 구분
