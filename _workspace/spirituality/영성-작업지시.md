## 5. 사용자 확정 필요 (Phase 2 착수 전 게이트)

다음 6가지에 답을 받지 못하면 제자 소집 시 산출물이 사용자가 원한 것과 어긋날 위험이 큼.

1. **신학 균형점:** SDA 정통 70 / 워맥 30 / 정체성·은혜 강조 — 비율 어디?
2. **12주 주제 선정 방식:**
   - (A) 워맥 7대 주제(영혼몸 / 권세 / 은혜와믿음 / 이미가졌다 / 노력없는변화 / 하나님제한금지 / 정체성)를 12주에 분배
   - (B) 입문→심화 단계형 (정체성 → 은혜 → 권세 → 안식 → 마음 → 사명)
   - (C) 남은자손 공동체 비전 중심 (계 12·14장 + 워맥 통합)
3. **첫 산출 우선순위:** 설교문 / 교재 / 슬라이드 중 어디부터?
4. **톤:** 강해설교형 / 묵상형 / 체험감화형 / 자기계발 진입자 친화형
5. **회당 분량:** 설교문(2천/4천/8천자), 교재(2/4/8쪽), 슬라이드(15/25/40매)
6. **워맥 1차 자료 접근:** 열린감리교회 유튜브 채널 정보·재생목록을 사용자가 제공해주실 수 있는지 (현재 환경에서 임의 유튜브 검색 권한 없음 — 안드레가 채널 URL/플레이리스트/주요 영상 텍스트를 받아야 매핑 가능)

## 6. Phase 2 착수 트리거

위 6개 답변 → 영성이 각 제자에게 구체 지시문 발행 → 병렬 탐구 시작 → 도마 검토 → 통합 보고서.

회당 12주 산출물은 **3주 단위 4 스프린트** (1–3주 / 4–6주 / 7–9주 / 10–12주) 로 분할 발행 권장. 한 번에 12주 풀버전을 쏟아내면 일관성·검수 모두 무너짐.
