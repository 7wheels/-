# 프로그램 예시

## 8주 기독교 마음챙김 과정

### 과정 개요
- 대상: 영성 성장에 관심 있는 성인 신앙인
- 형식: 주 1회 2시간 + 일일 개인 실천 15분
- 인원: 소그룹 8-12명

### 회차별 계획

**1주: 현재 순간과 하나님의 임재**
- 학습: 마음챙김의 기독교적 이해
- 실천: 호흡 기도 (5분) 소개
- 성경: 시편 46:10 "너는 가만히 있어 내가 하나님 됨을 알지어다"

**2주: 몸으로 드리는 예배**
- 학습: 몸의 신학 (성령의 전)
- 실천: 바디 스캔 명상 (기독교 버전)
- 성경: 로마서 12:1

**3주: 감사와 알아차림**
- 학습: 감사의 신학 (Eucharistia)
- 실천: 감사 마음챙김 + 저널링
- 성경: 빌립보서 4:6-7

**4주: 렉시오 디비나 심화**
- 학습: 4단계 성경 묵상법
- 실천: Lectio → Meditatio → Oratio → Contemplatio
- 성경: 직접 경험

**5주: 감정과 영적 분별**
- 학습: 감정의 신학 (이냐시오 영신 수련)
- 실천: 감정 마음챙김 + 성령의 내적 증거
- 성경: 갈라디아서 5:22-23

**6주: 영혼의 어두운 밤**
- 학습: 영적 건조함의 의미
- 실천: 건조함 속에서의 충실한 기도
- 성경: 시편 22편, 88편

**7주: 커뮤니티와 함께하는 침묵**
- 학습: 공동체 마음챙김의 의미
- 실천: 그룹 관상기도 (30분)
- 성경: 사도행전 2:1 오순절 공동 기다림

**8주: 일상으로의 통합**
- 학습: 일상 영성화 (Spirituality of Everyday Life)
- 실천: 개인 영성 루틴 설계
- 마무리: 서약 및 공동체 축복

## 소그룹 모임 구조 (90분)

```
0-10분:   마음챙김 체크인 (지금 이 순간 어떠세요?)
10-15분:  찬양 1곡 + 침묵 기도
15-35분:  말씀 나눔 (렉시오 디비나 방식)
35-55분:  주제 학습 + 소그룹 토의
55-75분:  실습 (명상·기도·저널링)
75-85분:  기도 제목 나눔
85-90분:  다음 주 실천 과제 + 축복 기도
```

## 리트릿 프로그램 (1박 2일)

### Day 1
- 14:00 도착 및 정착, 침묵 시작
- 15:00 오리엔테이션: 리트릿의 의미
- 16:30 개인 산책 마음챙김
- 18:00 저녁 식사 (침묵 식사)
- 19:30 저녁 기도: 시편 낭독 + 관상기도
- 21:00 취침 준비

### Day 2
- 07:00 아침 기도: 새벽 침묵
- 08:00 아침 식사
- 09:00 주제 강의: "하나님과 함께하는 현재 순간"
- 10:30 개인 렉시오 디비나
- 12:00 점심 식사
- 13:30 소그룹 나눔
- 15:00 마무리: 서약 + 파송 기도
- 16:00 해산

## 리더 양성 과정 (12주)

**목표:** 소그룹 영성 모임 리더 역량 개발

**모듈 구성:**
1. 영성 신학 기초 (3주)
2. 마음챙김 실천 훈련 (3주)
3. 그룹 퍼실리테이션 기술 (3주)
4. 영성 지도 입문 (3주)

**최종 평가:**
- 소그룹 모임 1회 직접 진행
- 슈퍼바이저 관찰 및 피드백
- 개인 영성 성찰 보고서 제출
