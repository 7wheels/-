### L2 — 교리

> *"하나님의 사람들 영역 = 외모 X / 중심 O. 자기 기준 X (W2) / 자기 무력화 X (W3). 사울→바울 / 다윗 / 약한 자 — 그분의 선택은 우리 기준 정반대일 수 있음."*

**거부하는 두 극단 (W2·W3 균형):**

❌ **극단 1 — 사람 절대화 (W2 회귀)**
- "○○이 카리스마니까 그분의 사람"
- 스타 사역자 절대화
- 외형 자격으로 한정
- 트랙 B W5 (개인 영웅주의) 친숙
- (왜 거부: 삼상 16:7 / 트랙 B W5 일관)

❌ **극단 2 — 사람 무력화 (W3 회귀)**
- "이 사람은 안 돼·자격 없어"
- "나도 자격 없어·부적합" (자기 무력화 포함)
- 외형 약함으로 한정
- (왜 거부: 사울→바울 / 다윗 / 자기 정죄 = 고소자 음성 22회째)

**5가지 통찰:**
1. 여호와는 중심을 보심 (삼상 16:7)
2. 사울→바울 — 우리 기준 정반대
3. 약한 자·문벌 없는 자 (고전 1:26-27)
4. 자기 기준 X (W2 균형)
5. 자기 무력화 X (W3 균형) + 만인제사장

**핵심 통찰:** **그분의 선택은 우리 기준의 정반대일 수 있다.** 사울→바울 / 다윗 / 기드온. 우리 기준 = 외모(*마르에*); 그분의 기준 = 중심(*레바브*). 자기 자격 X / 그분의 부르심 (만인제사장).
