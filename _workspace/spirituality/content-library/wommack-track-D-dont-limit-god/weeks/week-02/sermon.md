이 자리에서 우리는 5변형을 명시 거부합니다. 트랙 C W3 (의지 신앙 거부) 패턴과 같은 자리 — 다섯 가지 잘못된 형태를 하나씩 차단합니다.

## [L1 — 본문]

### 정욕으로 잘못 구함

> "구하여도 받지 못함은 **정욕으로 쓰려고 잘못 구하기 때문이라**." (약 4:3)

가장 강한 본문 중 하나. 정확히 봐야 합니다.

**핵심 1 — "구하여도 받지 못함은"** *아이테이테 카이 우 람바네테*(αἰτεῖτε καὶ οὐ λαμβάνετε)
- 야고보가 직접 가르치는 패턴
- 구하지만 받지 못함 — 본문이 인정
- "더 믿으면 다 받는다" 절대화 차단

**핵심 2 — "정욕으로"** *헤도나이스 휘몬*(ἡδοναῖς ὑμῶν)
- *헤도나이*(쾌락·욕망)
- 자기 욕망의 자리에서 구함
- 끌어당김의 법칙·자기 변혁이 정확히 이 자리

**핵심 3 — "잘못 구하기 때문이라"** *카코스 아이테이스데*(κακῶς αἰτεῖσθε)
- *카코스* — "나쁘게·잘못"
- 기도의 자리·동기의 자리가 잘못
- 무엇을 구하느냐가 척도 X / **어떻게·왜 구하느냐**

**핵심 4 — 다음 절 (약 4:4)**
- "간음한 여인들아 ... 세상과 벗 됨이 하나님과 원수 됨"
- 본문이 매우 강한 어조
- 자기 욕망 절대화가 영적 간음

### 그의 나라와 그의 의를 먼저

> "너희는 먼저 **그의 나라와 그의 의를 구하라** 그리하면 이 모든 것을 너희에게 더하시리라." (마 6:33)

기대의 우선순위 본문.

**핵심 1 — "먼저"** *프로톤*(πρῶτον)
- 순서가 결정적
- 외형 필요 X / **그의 나라·의** O
- 기도의 출발점 자체가 다름

**핵심 2 — "그의 나라와 그의 의"**
- *바실레이아 + 디카이오쉬네 아우투*
- 그분의 통치 + 그분의 의
- 자기 욕망 X / **그분의 자리**

**핵심 3 — "더하시리라"** *프로스테데세타이*(προστεθήσεται)
- "더하여진다"
- 부산물 — 외형이 따라옴
- 외형 자체를 직접 구하는 자리 X

**핵심 4 — 이전 절 (마 6:32)**
- "이는 다 이방인들이 구하는 것이라"
- 외형 직접 구함 = 이방인의 자리
- 트랙 F W6 절대 일관

### 자족하기를 배웠노니

> "어떠한 형편에든지 **내가 자족하기를 배웠노니** ... 내게 능력 주시는 자 안에서 내가 모든 것을 할 수 있느니라." (빌 4:11-13)

번영복음 차단의 가장 강한 본문 — 트랙 B W3에서 본 자리.

**핵심 1 — "자족"** *아우타르케스*(αὐτάρκης)
- "스스로 충분함"
- 외형 끌어오기 X / **내면의 충분함**
- 트랙 B W3 일관

**핵심 2 — "배웠노니"** *에마톤*(ἔμαθον)
- 부정과거 — "배웠다"
- 즉시 X / 평생의 자리
- 자기 외형 통제 X / 받음의 자리

**핵심 3 — "내게 능력 주시는 자 안에서"**
- 트랙 A 갈 2:20 척추 일관
- 내주의 능력 — 외형 능력 X
- 트랙 B W3 휘페르니카오멘 일관

**핵심 4 — "모든 것을 할 수 있느니라"의 정확한 의미**
- "비천에 처할 줄도 알고 풍부에 처할 줄도 알며" (빌 4:12)
- 외형 풍부 + 외형 비천 둘 다
- "내가 모든 것을 끌어올 수 있다" X / **모든 상황에서 자족할 수 있다** O

세 본문이 함께 기대 과잉의 5변형을 차단합니다 — **정욕 X / 우선순위 그분의 나라 / 외형 통제 X / 자족.**

### 우리의 자리 — 자족 + 그의 나라 우선

> *"기대 과잉·번영복음 5변형 절대 차단. 외형 끌어오기 X / 자기 욕망 절대화 X / 시각화·자기 변혁 X / '이미 다 받았다' 절대화 X / 자기 시간표 강요 X. 자족 + 그의 나라 우선 + 내주의 능력."*

**5가지 통찰:**

1. **정욕으로 잘못 구함** — 약 4:3 헤도나이스·카코스 아이테이스데

4. **번영복음 5변형 절대 거부** — 트랙 F W6 절대 일관
5. **내주의 능력** — 갈 2:20 척추 / 외형 능력 X

### 트랙 일관

- **번영복음 5변형 거부** = 트랙 F W6 절대 일관 / 어휘 방화벽 절대
- **자족** = 트랙 B W3 (환경 영역) 일관
- **끌어당김의 법칙·자기 변혁 거부** = 트랙 E W4 일관
- **자기 정죄 = 고소자 음성** = 5트랙 누적 20회 / 본 회당 **21회째 누적**
- **사랑이 척도 (W8 예고)** = 트랙 B W6 + E W8 일관

오늘 한 문장 — **"하나님을 제한하지 마라"가 자기 욕망 절대화로 빠질 수 없다. 5변형 절대 차단. 자족 + 그의 나라 우선 + 내주의 능력.**

## [L3 — 마음공부]

자기 안의 기대 과잉 흔적을 정직하게 봅니다.

**⚠ 자기 정죄 자리로 빠지지 않게.** 평생 번영복음 어법에 친숙했던 분도 받음의 자리로 돌아옵니다. 자기 정죄는 고소자 음성 (계 12:10) — 5트랙 누적 21회째.

### 자기 진단 — 번영복음 5변형 점검

**1. 외형 끌어오기형 (끌어당김의 법칙)**
- 시각화·"마음에 그리면 이뤄짐"

- 끌어당김의 법칙 어법

**2. 자기 욕망 절대화형**
- "내가 원하는 것 = 하나님의 뜻"
- "하나님 제한 X" 어법 오용
- 자기 욕망을 영적 자리로

**3. 시각화·자기 변혁형**
- "이미 받은 것처럼"
- 자기 변혁(self-transformation)

**4. "이미 다 받았다" 절대화형**

**5. 자기 시간표 강요형**
- "이번 주 안에·당장"

- 자기 의지로 압박

### 깊은 자리의 통찰

본문이 가르치는 가장 깊은 자리 — **자기 욕망이 아무리 강해도 그것이 곧 그분의 뜻은 아니다**입니다. 약 4:3 — 정욕으로 잘못 구함. 마 6:32 — 외형 직접 구함은 이방인의 자리. 트랙 F W6에서 본 번영복음 차단이 트랙 D에서 다시 — 같은 어법.

또 하나 — **"하나님을 제한하지 마라"는 자기 욕망 절대화의 정당화 X / 자기 시간표·방법·한계 내려놓음**입니다. 트랙 D 전체의 의도는 자기 욕망을 키우는 것이 아니라 **그분의 자리를 받는 것**.

지금 자신에게 물어보십시오 (안전한 자기 점검 자세로).
- 5변형 중 자기에게 가까운 것은?
- 평생 끌어당김의 법칙·자기 변혁 어법에 친숙했던 자리는?
- 자기 욕망을 "하나님의 뜻"으로 환원한 흔적은?
- 자족(빌 4:11)이 자기에게 어떻게 들리는가?

**주의:** 자기 점검이 자기 정죄로 빠지지 않게 (계 12:10). 트랙 F (받음의 자리)부터 다시 권유 가능.
