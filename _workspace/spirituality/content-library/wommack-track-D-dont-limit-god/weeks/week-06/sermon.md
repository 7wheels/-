# 트랙 D · Week 6 — 기대의 4영역 3: 하나님의 방법
## (모로스 — 어리석은 것, 아스데네스 — 약한 것)

> 본문: 이사야 55:8-9 / 고린도전서 1:25-27 / 사사기 7
> 분량: 약 4,000자 / 30~40분
> 도마 검토 ★★ — "하나님의 방법" 자리 / 자기 신학 환원 위험

---

## [도입]

지난 두 주 동안 우리는 기대의 첫 번째·두 번째 영역 — 능력(W4)·시간표(W5) — 를 봤습니다. 이번 주는 세 번째 영역 — **하나님의 방법.**

기대의 좌절은 종종 방법 자리에서 옵니다. "이렇게 응답하실 줄 알았는데 저렇게 응답하셨다." "내가 생각한 방법이 아니다." 우리는 평생 자기 방법으로 그분을 제한해 왔습니다.

본문은 이사야 55장 8-9절 — 가장 강한 방법 본문.

---

## [L1 — 본문]

### 내 생각·내 길이 다름

> "이는 **내 생각이 너희의 생각과 다르며 내 길은 너희의 길과 다름이니라** 여호와의 말씀이니라. 이는 하늘이 땅보다 높음 같이 내 길은 너희의 길보다 높으며 내 생각은 너희의 생각보다 높음이니라." (사 55:8-9)

방법 신학의 가장 강한 본문.

**핵심 1 — "내 길"** *데레키*(דְּרָכַי)
- 히브리어 — 길·방법
- 그분의 방법 ≠ 우리 방법
- 자기 방법으로 그분 한정 X

**핵심 2 — "하늘이 땅보다 높음 같이"**
- 거리의 비유
- 우리 추측의 자리에 없음
- 카리스마적 "그분 방법 알았다" 어법 차단 (W10 예고)

**핵심 3 — "내 생각"** *마흐셰보타이*(מַחְשְׁבוֹתַי)
- 사고·계획
- 우리 신학 환원 X
- 시 78:41 일관 — 우리가 그분 제한

### 어리석은 것·약한 것·천한 것

> "하나님의 **어리석음이 사람보다 지혜롭고** 하나님의 **약하심이 사람보다 강하니라** ... **세상의 미련한 것들**을 택하사 지혜 있는 자들을 부끄럽게 하려 하시고 **세상의 약한 것들**을 택하사 강한 것들을 부끄럽게 하려 하시며 ... **천한 것들과 멸시 받는 것들**과 없는 것들을 택하사 있는 것들을 폐하려 하시나니." (고전 1:25-28)

방법 신학의 두 번째 본문 — 정반대 자리.

**핵심 1 — "어리석음"** *모리아*(μωρία) — *모로스*(μωρός) 어근
- 헬라어 — "바보스러움"
- 그분의 방법은 우리 지혜의 정반대
- 십자가의 어리석음 (고전 1:18)

**핵심 2 — "약함"** *아스데네스*(ἀσθενής)
- "약한·연약한"
- 그분의 방법은 우리 강함의 정반대
- 자기 자원·강함으로 그분 제한 X

**핵심 3 — 4가지 자리**
- 미련한 것(*모로스*)
- 약한 것(*아스데네스*)
- 천한 것(*아게네스*)
- 멸시 받는 것(*엑수데네메나*)
- **모두 우리가 무시하는 자리**

**핵심 4 — "있는 것들을 폐하려"**
- 자기 강함·지혜·자리를 폐함
- 자기 방법 절대화 X
- W2 회귀 차단

### 기드온의 300명

> 사사기 7장: 32,000명 → 10,000명 → 300명. 자기 자원의 정반대.

**핵심 1 — 자기 자원 줄임**
- 32,000명 (자기 자원 자랑) → 10,000 → 300
- 그분의 방법 = 자기 자원의 정반대
- "이스라엘이 나를 거슬러 자랑하기를 내 손이 나를 구원하였다 할까 하노라" (삿 7:2)

**핵심 2 — 300명·횃불·항아리**
- 군사적 자원 X / 빛과 소리
- 자기 방법 완전 정반대
- 시 78:41 일관 — 우리 자원 자랑이 그분 제한

**핵심 3 — 평생 우리에게 적용**
- 자기 자원·방법·계획으로 그분 한정
- 그분의 방법은 자주 정반대
- W2·W3 둘 다 차단

세 본문이 함께 방법 신학을 가르칩니다 — **그분의 길 ≠ 우리 길 + 어리석은 것·약한 것 사용 + 자기 자원의 정반대.**

---

## [L2 — 교리]

이 자리에서도 두 극단을 거부합니다.

### 거부하는 극단 1 — 자기 방법 절대화 (W2 회귀)

**잘못된 주장:**
- "내가 알고 있는 방법대로 응답해 주실 것"
- 자기 신학·자기 경험·자기 사역 방법 절대화
- 카리스마적 "그분 방법 알았다" 어법
- "이렇게 기도하면 이렇게 응답하신다" 공식화

**왜 거부하는가:**
- 사 55:8-9 — "내 길은 너희의 길과 다름"
- 고전 1:25-28 — 어리석은 것·약한 것 사용
- 삿 7 — 정반대의 자리
- 카리스마적 "방법 알았다" — W10 분별 차단 일관

### 거부하는 극단 2 — 신학적 방법주의 회피 (W3 회귀)

**잘못된 주장:**
- "이젠 그런 기적적 방법은 없다"
- 신학적 형태로 방법 자리 한정
- 세대주의 일부 어법
- W3 운명론과 같은 자리

**왜 거부하는가:**
- 히 13:8 — "어제나 오늘이나 영원토록 동일"
- 그분의 방법 영역에 시대 제한 X
- 트랙 F W5 (신유) 일관

### 우리의 자리 — 그분의 방법 받음

> *"하나님의 방법 영역 = 우리 방법의 정반대일 수 있음. 자기 방법 절대화 X (W2) / 방법주의 회피 X (W3). '내 길 ≠ 너희 길' + '어리석은 것·약한 것'."*

**5가지 통찰:**

1. **그분의 길 ≠ 우리 길** — 사 55:8-9
2. **어리석은 것·약한 것 사용** — 고전 1:25-28
3. **자기 자원의 정반대** — 기드온 300명
4. **자기 방법 절대화 X** — W2 균형
5. **방법주의 회피 X** — W3 균형

### 트랙 일관

- **W2·W3 균형** = W4·W5 패턴 일관
- **카리스마적 "방법 알았다" 차단** = W10 영적 분별 예고 (트랙 B W10·E W10 일관)
- **자기 정죄 = 고소자 음성** = 5트랙 누적 22회

오늘 한 문장 — **하나님의 방법 영역 = 우리 방법의 정반대일 수 있음. 자기 방법 X / 방법주의 회피 X / 그분의 방법 받음.**

## [L3 — 마음공부]

자기 안의 방법 영역 자세를 정직하게 봅니다.

### 자기 진단 — 3자세

**1. 자기 방법 절대화형 (W2 회귀)**
- "내가 알고 있는 방법대로"
- 자기 신학·경험·사역 방법 절대화
- "이렇게 기도하면 이렇게 응답하신다" 공식
- 카리스마적 "방법 알았다"

**2. 방법주의 회피형 (W3 회귀)**
- "이젠 그런 기적적 방법 없다"
- 신학적 형태로 한정
- 세대주의 일부

**3. 그분의 방법 받음형 (이상)**
- 우리 방법의 정반대일 수 있음 인정
- 자기 방법 절대화 X
- 어리석은 것·약한 것 받음
- 자기 자원 자랑 X

### 깊은 자리의 통찰

본문이 가르치는 가장 깊은 자리 — **그분의 방법은 자주 우리 방법의 정반대**입니다. 고전 1:25-28 — 미련한 것·약한 것·천한 것·멸시 받는 것을 택하심. 기드온 300명. 십자가 자체가 가장 큰 어리석음.

또 하나 — **자기 자원·방법·신학으로 그분 한정 X**입니다. 시 78:41 일관 — 우리가 평생 자기 길로 그분 제한해 왔음.

지금 자신에게 물어보십시오.
- 평생 자기 방법으로 그분을 한정해 온 자리는?
- "이렇게 응답하실 줄 알았는데" 정반대로 오신 경험은?
- 어리석은 것·약한 것이 그분의 자리라는 통찰이 자기에게?

## [L4 — 실천]

이번 주 한 가지 실천 — **자기 방법 내려놓음 + "어리석은 것·약한 것" 받음, 매일 15분.**

```
1. 자세·호흡 2분

2. 갈 2:20 + 사 55:8-9 낭독
   "내 길은 너희의 길과 다름이니라"

3. 자기 방법 알아차림 5분
   현재 자기가 그분에게 기대하는 방법 1자리:
   ① 자기 방법 절대화 흔적?
   ② 방법주의 회피 흔적?
   ③ 그분의 방법 받음의 자리?

4. "어리석은 것·약한 것" 받음 호흡 5분
   - 들숨: "내 길은 너희의 길과 다름이니라"
   - 날숨: "어리석은 것·약한 것을 받습니다"
   - 자기 자원 내려놓음
   - 그분의 방법 받음

5. 마무리 침묵 3분
```

**일상의 호흡 (이번 주 매일)**

| 자리 | 호흡 |
|---|---|
| 자기 방법 절대화 시 (W2 회귀) | "내 길은 너희의 길과 다름" |
| 방법주의 회피 시 (W3 회귀) | "어제나 오늘이나 영원토록 동일" |
| 자기 자원 자랑 시 | "기드온 300명" |
| 받음의 자리 시 | "어리석은 것·약한 것 받음" |

**핵심:** 자기 방법 X / 방법주의 회피 X / **그분의 방법 받음** O.

**안전장치:**
- W2 회귀 — "내가 알고 있는 방법대로" 절대 X
- W3 회귀 — "이젠 그런 방법 없다" X
- 카리스마적 "방법 알았다" X (W10 분별 예고)
- 자기 정죄 X (계 12:10) — 22회째

## [마무리]

길이 우리 길과 다르신 그리스도여,
당신은 우리에게 그분의 방법이
우리 추측의 자리에 없음을 가르치셨습니다.
어리석은 것·약한 것·천한 것을 사용하시며
기드온의 300명처럼 자기 자원의 정반대로 일하십니다.

평생 자기 방법으로 당신을 한정해 온 우리,
또는 신학으로 당신의 방법을 회피해 온 우리를 받으소서.
"내 길은 너희의 길과 다름이니라"의 자리에서
어리석은 것·약한 것을 받게 하소서.

이미 우리 안에 사시는 그리스도, 우리 길보다 높으신 분의 이름으로. 아멘.

> *"내 생각이 너희의 생각과 다르며 내 길은 너희의 길과 다름이니라."* (사 55:8)
