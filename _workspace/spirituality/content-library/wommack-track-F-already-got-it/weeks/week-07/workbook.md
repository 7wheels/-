## [2쪽 — L1 본문 묵상 + L2 교리]

### L1 — 본문 묵상

**관찰 5개**

1. 마 28:18 "주셨으니"의 헬라어 에도데(부정과거 수동)는 부활 시점에 그리스도가 받으심을 의미한다. 이것이 우리에게 위임된 권세의 출발점에 어떻게 닿는가?

2. 눅 10:19 권세가 마술적·신비주의적이 아닌 무엇인가? — 본문이 가리키는 것은?

3. 엡 1:19-22 "능력의 지극히 크심" — 그리스도의 머리되심과 우리의 권세는 어떻게 연결되는가?

4. 권세 절대화와 권세 무력화 두 극단을 동시에 거부하는 길은?

### L2 — 교리

> *"권세 = 그리스도가 부활로 받으심 + 우리에게 위임. 우리 능력 X / 그리스도의 몸으로서 권한 O."*

**거부하는 두 극단:**
- ❌ 권세 절대화 (모든 환경 통제·기도 만능·영적 우월감)
- ❌ 권세 무력화 ("사도 시대 끝"·신자에게 권세 없음·신비주의로 치부)

**다섯 원칙:**
1. 그리스도가 받으심
2. 우리에게 위임됨
3. 개인 마술 X / 몸으로서
4. 사용 안 하면 잠듦
5. **사랑이 척도** (고전 13)

**권세의 4영역:**
- 자기 / 환경 / 악 / 사역
