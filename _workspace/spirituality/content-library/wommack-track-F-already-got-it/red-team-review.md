## 5. 트랙 C 진입 전 권고

트랙 F의 학습을 트랙 C에 가져갈 때 도마가 강조하는 5가지:

1. **W1·W11 받음의 어휘 패턴 반복 — 트랙 C** 받음의 매커니즘을 다룰 때 어휘 일관 유지. RF1 잔여 위험 동일 적용.

2. **W2·W6 함정 차단 패턴 — 트랙 C** 행위 면죄부·번영복음 회귀 가능. 매 회당 W3 트랙 A 균형 적용.

3. **W7 권세·W8 뜻 다리 — 트랙 C** 트랙 C가 받음의 매커니즘이라면 트랙 B·G의 다리 역할도 함. 통합 신학 진술서 명제 4·6 함께 사용.

4. **자기 정죄 = 고소자 음성 어법** — 트랙 C에서도 동일 적용 (W2·W9 패턴).

5. **저장소 분리 결정 시점** — 라인 수 24,110 → 트랙 C가 약 10,000 추가 시 임계 30,000 초과. **트랙 C 시작 전 분리 결정 필수.**
