## [도입]

지난 주 W2에서 — 번영 복음 거부 ★★★★. "믿으면 부자"·"헌금 = 보상"·"선언·시각화"·"부 = 영적 증거"·"100배 강박" 5변형 명시 차단.

오늘 W3 — 정반대 극단 — **가난 영성(Poverty Spirituality) 거부.**

가난 영성이란? "**돈은 더러움·악 / 가난해야 영적 / 일은 죄책감 / 재정 자체 회피 / 자발적 빈곤 강박.**" 번영 복음과 정반대지만 동일하게 비성경적입니다.

왜 이것도 거부하는가? 세 가지 이유.

첫째 — **성경의 직접 거부.** 신 8:18 "재물 얻을 능력 주심" / 잠 10:22 "여호와의 복은 부하게 함" / 전 5:18-20 "수고의 결과 즐김".

둘째 — **재정 책임 회피.** 가난 영성은 영성의 이름으로 일·계획·청지기직을 회피하는 자리가 됩니다. W6 (받음과 일하기)와 정반대.

셋째 — **임상 피해.** 강박적 자린고비·자발적 빈곤 강박·우울·일 죄책감·관계 단절. R3·R6 필요.

오늘 한 자리 — **가난 영성 거부. 돈 = 악 X / 가난 = 영적 X / 일 죄책감 X.** 이로써 양극단 동시 거부 완성.

## [L1 — 본문]

### 재물 얻을 능력을 네게 주셨음이라

> "**그러나 네 하나님 여호와를 기억하라 그가 네게 재물 얻을 능력을 주셨음이라** 이같이 하심은 ... 그 언약을 이루려 하심이니라." (신 8:18)

가난 영성 거부의 가장 명확한 본문.

**핵심 1 — "재물 얻을 능력"** *코아흐 라아쇼트 하일*(כֹּחַ לַעֲשׂוֹת חָיִל)
- *코아흐* — 능력·힘
- *하일* — 재물·부·역량
- 재물 얻음 = 하나님이 주신 능력
- "돈은 악" 직접 거부

**핵심 2 — "여호와를 기억하라"**
- 받음의 자리 — 자기 능력 X / 받은 능력
- 신 8:17 직전 본문 — "내 능력과 내 손의 힘으로 ... 얻었다" 차단
- 청지기 시각 (W1 일관)

**핵심 3 — "언약을 이루려 하심"**
- 재정 능력 = 언약의 일부
- 재정 = 거룩한 도구
- 가난 영성의 "돈은 거룩하지 않음" 직접 거부

### 여호와께서 복을 주시므로 부하게 하시고

> "**여호와께서 주시는 복은 사람을 부하게 하고 근심을 겸하여 주지 아니하시느니라**." (잠 10:22)

부 자체에 대한 긍정 본문.

**핵심 1 — "여호와께서 주시는 복"** *비르카트 아도나이*(בִּרְכַּת יְהוָה)
- *베라카* — 복·축복
- 부가 복의 일부
- "부 = 악" 직접 거부

**핵심 2 — "사람을 부하게 하고"** *히 타아쉬르*(הִיא תַעֲשִׁיר)
- *아샤르* — 부하게 함
- 부 자체 = 하나님의 복의 자리
- 단, 부가 영적 증거 X (W2 거부)

**핵심 3 — "근심을 겸하여 주지 아니하시느니라"**
- 부와 근심의 분리
- 자력으로 모은 부 (근심 동반) vs. 받은 복 (근심 X)
- 받음의 자리 강조

### 수고의 결과 즐기는 것이 하나님의 선물

> "사람마다 하나님이 그에게 재물과 부요를 주사 ... 자기 분복을 받아 **수고함으로 즐거워하게 하신 것은 하나님의 선물이라**." (전 5:19)

일과 재정의 신학적 긍정.

**핵심 1 — "하나님이 그에게 재물과 부요를 주사"** *솅 마트나트 엘로힘 히*(שֶׁמַּתַּת אֱלֹהִים הִיא)
- *마트나트 엘로힘* — 하나님의 선물
- 재정·부요 = 하나님의 선물 (악 X)
- 받음의 자리

**핵심 2 — "수고함으로 즐거워하게"**
- *아말* — 수고·노동
- 일의 결실 = 즐거움 (죄책감 X)
- "일은 죄책감" 가난 영성 직접 거부

**핵심 3 — "하나님의 선물이라"**
- 일·재정·즐거움 = 선물
- 가난 영성의 "즐거움은 영적이지 않음" 거부
- W10 (단순한 삶 / 즐거움) 예고

세 본문이 함께 가르칩니다 — **재물 얻을 능력 = 하나님이 주심 / 여호와의 복이 부하게 함 / 일의 결실 = 하나님의 선물. 가난 영성 ≠ 영성.**

## [L2 — 교리]

이 자리에서는 또 다른 극단 — 가난 영성 — 을 거부합니다. W2 번영 + W3 가난 = 양극단 동시 거부 완성.

### 거부하는 극단 — 가난 영성 (★★★)

가난 영성 5변형을 명시 거부합니다.

**변형 1 — "돈은 더러움·악"**
- 돈 자체 = 죄·악·세속
- 딤전 6:10 오용 — "돈을 사랑함" ≠ "돈 자체"
- 신 8:18 직접 거부

**변형 2 — "가난해야 영적"**
- 빈곤 = 영적 우월
- 부 = 영적 열등
- 잠 10:22 직접 거부
- 욥·아브라함·다윗 부자였으나 의인

**변형 3 — "일은 죄책감"**
- 직업·돈 버는 것에 대한 죄책감
- 영성과 일 분리
- 전 5:19 직접 거부
- W6 (받음과 일하기) 예고

**변형 4 — "자발적 빈곤 강박"**
- 강박적 절제·재정 회피
- 두려움 기반 절약
- R6 임상 신호 (강박 ★★★)

**변형 5 — "재정 책임 회피"**
- 영성의 이름으로 계획·예산·저축 회피
- "오늘만 살자" 무책임
- 눅 16:10 (작은 것에 충성) 거부
- 미래 청지기직 무시

### 왜 거부하는가 (다중 근거)

- **신 8:18** — 재물 얻을 능력은 하나님이 주심
- **잠 10:22** — 여호와의 복이 부하게 함
- **전 5:18-20** — 일·재정 = 하나님의 선물
- **창 1:28** — 땅을 다스리라 (청지기직)
- **눅 19 달란트 비유** — 받은 자원 잘 운용
- **욥·아브라함·다윗** — 부자 의인의 성경 모범

### 거부 안에서 보호할 진실

오해 차단 — 가난 영성 거부 ≠ 다음:
- 번영 복음 회귀 X (W2 일관)
- 부 추구 정당화 X (W2 5변형 여전히 거부)
- 부자 우월·가난 정죄 X (마 5:3 / 약 2:5 일관)
- 자발적 단순한 삶 거부 X (W10에서 다룸 — 강박 X / 자유 O)

### 우리의 자리 — 가난 영성 거부 (양극단 완성)

> *"가난 영성 거부 ★★★. 돈 = 악 X / 가난 = 영적 X / 일 죄책감 X. W2 번영 + W3 가난 = 양극단 동시 거부 완성."*

**5가지 통찰:**

1. **코아흐 라아쇼트 하일** — 재물 얻을 능력은 하나님이 주심 (신 8:18)
2. **비르카트 아도나이** — 여호와의 복이 부하게 함 (잠 10:22)
3. **솅 마트나트 엘로힘** — 일·재정 = 하나님의 선물 (전 5:19)
4. **5변형 명시 거부** — 돈 악·가난 영적·일 죄책감·자발적 빈곤 강박·재정 회피
5. **양극단 완성** — 번영(W2) + 가난(W3) 동시 거부 → 청지기 균형

### 트랙 일관
