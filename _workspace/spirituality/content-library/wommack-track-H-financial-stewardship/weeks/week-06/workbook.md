### L2 — 교리

> *"재정 분별 1 = 받음 + 일하기. 자력 종교 X / 게으름·회피 X. 받은 능력으로 청지기직."*

**거부하는 두 극단:**

❌ **극단 1 — 자력 종교 ("내가 벌었음")**
- "내가 일한 만큼 벌었음" 자기 공로
- 받음 무시·청지기 시각 부재
- (왜 거부: 신 8:17 직접 거부 대상 / 신 8:18 능력은 받음 / 트랙 E W2 자력 거부)

❌ **극단 2 — 게으름·재정 회피**
- "하나님이 다 주실 거니까 일 안 해도"
- "재림 임박하니 일 의미 없음" (살후 3 문맥)
- "기도만 하면 됨" 책임 회피
- (왜 거부: 살후 3:10 직접 명령 / 잠 10:4 / 전 9:10 / W3 가난 영성 일관)

**5가지 통찰:**
1. 에르가조마이 — 일하기는 청지기직 (살후 3:12)
2. 아탁토스 X — 게으름·무질서 거부 (살후 3:11)
3. 하루츠 — 부지런이 부의 자리 (잠 10:4)
4. 콜 아쉘 티므차 야드카 — 손이 얻는 일에 힘껏 (전 9:10)
5. 받음 + 일하기 균형 (자력 X / 회피 X)

**핵심 통찰:** **받음과 일하기는 분리되지 않는다.** 신 8:18 — 재물 얻을 능력 = 하나님이 주심. 능력의 사용 = 일. 자력 종교는 받음을 무시 / 게으름은 일을 무시. 진실은 **받은 능력으로 힘껏 일하고 결과도 받음으로 인정**.

⚠ **번영 약속 X (W2 일관):** "부지런 → 보장된 부" X. 시 73편 — 악인도 부함. 부지런은 일반 원리이지 보장이 아님.

⚠ **임상 안전:** 일 못하는 상황 (질병·실직·돌봄 부담) 자기 정죄 X. 동시에 무책임 회피도 X.
