# 트랙 H · Week 4 — 명시된 청지기 1: 십일조
## (마아세르·아포데카토오 — 말 3:8-10 / 창 14:20 / 마 23:23)

> 본문: 말라기 3:8-10 / 창세기 14:20 / 마태복음 23:23
> 분량: 약 4,000자 / 30~40분
> 도마 검토 ★★★ — SDA 정체성 핵심 + 율법주의 위험

## [도입]

W1-W3에서 — 청지기 정의 + 양극단 동시 거부 (번영·가난).

오늘 W4 — 양극단 거부 후 **명시된 청지기 본격**. 첫 자리는 **십일조(Tithe).**

십일조는 두 위험 사이에 놓여 있습니다.

위험 1 — **율법주의 십일조:** "안 하면 저주 / 정확히 십분의 일 / 강요·압박 / 자기 의 자랑." 한국 교회에서 광범위.

위험 2 — **십일조 거부:** "은혜 시대니까 필요 없음 / 자유로운 헌금만 / 율법 끝남." 일부 은혜 강조 흐름.

성경은 둘 다 거부합니다. **십일조 = 명시된 청지기 / 율법주의 X / 자유로운 헌신 O.** 창세기(아브라함)·말라기·신약(마 23:23 "이것도 행하고 저것도 버리지 말아야") 일관.

SDA 정통은 십일조를 청지기 신학의 핵심으로 봅니다. **율법주의가 아닌 받음에서 흐르는 헌신** — 이것이 W4의 자리입니다.

## [L1 — 본문]

### 너희가 어떻게 나의 것을 도둑질하였느냐 십일조와 봉헌물이라

> "사람이 어찌 하나님의 것을 도둑질하겠느냐 그러나 너희는 나의 것을 도둑질하고도 말하기를 우리가 어떻게 주의 것을 도둑질하였나이까 하는도다 이는 곧 **십일조와 봉헌물이라** ... **온전한 십일조를 창고에 들여 ... 그것으로 나를 시험하여 ... 내가 너희에게 ... 부어 줄 복을 시험하여 보라**." (말 3:8-10)

십일조의 가장 강력한 본문.

**핵심 1 — "도둑질"**
- 청지기 신학의 강력한 비유 — 십일조 = 하나님 것
- W1 시 24:1 일관 — 다 여호와의 것
- 십일조 = "원래 그분의 것"의 인정

**핵심 2 — "온전한 십일조"** *콜 하마아세르*(כָּל הַמַּעֲשֵׂר)
- *마아세르* — 십분의 일·십일조
- *콜* — 온전한·완전한
- 일부 X / 온전함

**핵심 3 — "나를 시험하여 보라"**
- 하나님이 시험 허용한 유일 자리
- 신 6:16 "시험하지 말라"와 구분
- 청지기직 약속

⚠ **주의 — 번영 복음 차단 (W2 일관):**
- "복을 시험하여 보라" = 받음의 약속
- 그러나 **재정 100배 약속 X** (W2 거부)
- 영적·관계적·청지기 회복 약속 포함
- "내가 헌금하면 부자 됨" 오용 차단

### 그가 모든 것의 십분의 일을 ... 십일조로 주었더라

> "지극히 높으신 하나님이 ... 너의 대적을 네 손에 붙이셨음이로다 하매 아브람이 **그 얻은 것에서 십분의 일을 멜기세덱에게 주었더라**." (창 14:18-20)

율법 이전의 십일조 — 토대.

**핵심 1 — "그 얻은 것에서 십분의 일"**
- 율법(시내산) 430년 이전
- 아브라함 자발적 헌신
- 십일조 = 율법 이전의 영원한 원리

**핵심 2 — "멜기세덱에게"**
- 살렘 왕·지극히 높으신 하나님의 제사장
- 히 7:1-10 — 그리스도의 예표
- 신약에서도 유효한 원리 (히 7:8 "받는 자는 살아 있다 증거된 자")

**핵심 3 — 신약 적용 (히 7:1-10)**
- 십일조 = 율법주의 X / 영원한 원리
- 그리스도 안에서 자유로운 헌신
- 강제 X / 받음

### 너희가 박하와 회향과 근채의 십일조는 드리되 ... 이것도 행하고 저것도 버리지 말아야 할지니라

> "화 있을진저 외식하는 서기관들과 바리새인들이여 너희가 **박하와 회향과 근채의 십일조는 드리되 율법의 더 중한 바 정의와 긍휼과 믿음은 버렸도다** **그러나 이것도 행하고 저것도 버리지 말아야 할지니라**." (마 23:23)

신약 시대의 십일조 — 예수님의 직접 가르침.

**핵심 1 — "박하와 회향과 근채의 십일조는 드리되"**
- 작은 식물 십일조까지 드림 — 율법 준수 인정
- 예수님이 십일조 자체 거부 X
- **십일조 = 신약에서도 유효** (예수님 직접 확인)

**핵심 2 — "율법의 더 중한 바 정의와 긍휼과 믿음은 버렸도다"**
- 십일조 + 정의·긍휼·믿음 (G W5 일관)
- 십일조만 X / 사랑이 척도 함께 (W8 예고)
- 율법주의 차단

**핵심 3 — "이것도 행하고 저것도 버리지 말아야 할지니라"** *타우타 데 에데이 포이에사이*
- **십일조도 행하라** (예수님의 직접 명령)
- 동시에 정의·긍휼·믿음도
- 둘 다

세 본문이 함께 가르칩니다 — **십일조 = 율법 이전의 영원한 원리(창 14) + 청지기 신학의 핵심(말 3) + 신약에서도 유효(마 23). 율법주의 X / 자유로운 헌신 O.**

## [L2 — 교리]

이 자리에서도 두 극단을 거부합니다.

### 거부하는 극단 1 — 십일조 율법주의

**잘못된 주장:**
- "십일조 안 하면 저주받음"
- 강요·압박·자기 의 자랑

- 헌금 안 한 자 정죄
- 트랙 E W2 자력 변화 패턴

**왜 거부하는가:**
- 말 3:10 "시험하여 보라" — 자발적 자리
- 창 14 아브라함 — 자발적 헌신
- 고후 9:7 — "자원하는 마음" (W5 본격)
- 마 23:23 정의·긍휼·믿음 함께 (사랑 척도)

### 거부하는 극단 2 — 십일조 거부 (은혜 시대 핑계)

**잘못된 주장:**
- "은혜 시대니까 십일조 필요 없음"
- "구약 율법은 끝남"
- "마음에서 드리면 됨" (실제 드림 회피)
- 청지기 책임 회피

**왜 거부하는가:**
- 마 23:23 "이것도 행하고" — 예수님 직접 명령
- 창 14 — 율법 이전 (영원한 원리)
- 히 7:1-10 — 멜기세덱 차원 유효
- W3 재정 책임 회피 변형

### 우리의 자리 — 자유로운 헌신으로서의 십일조

> *"십일조 = 명시된 청지기. 율법주의 X / 거부 X. 받음에서 흐르는 자유로운 헌신."*

**5가지 통찰:**

1. **콜 하마아세르** — 온전한 십일조 (말 3:10)
2. **시험하여 보라** — 청지기직 약속 (번영 100배 X / W2 일관)
3. **창 14 아브라함** — 율법 이전의 영원한 원리
4. **마 23:23 이것도 행하고** — 신약 유효 + 정의·긍휼·믿음 함께
5. **자유로운 헌신** — 율법주의 X / 거부 X / 받음에서 흐름

### SDA 청지기 신학 일관

SDA는 십일조를 청지기 신학의 핵심으로 봅니다:
- 시 24:1 — 다 여호와의 것 (W1 토대)
- 말 3:10 — 온전한 십일조
- 마 23:23 — 신약 유효
- 십일조 = 사역·구원의 일·교회 사역에
- 율법주의 X / 받음에서 흐름

**SDA 정체성 보호:**
- 십일조 자체 거부 X (W4 거부 — 은혜 시대 핑계)
- 율법주의화 X (W4 거부 — 강요·저주)
- 자발적·자유로운 헌신 (고후 9:7 — W5 본격)

### 트랙 일관

- **율법주의 X** = 트랙 E W2 (자력)·C W3 (의지 신앙) 일관
- **재정 회피 X** = 트랙 H W3 (가난 영성) 일관
- **번영 약속 X** = 트랙 H W2 일관 — 말 3 "시험하여 보라"의 영적 의미
- **사랑 척도** = 마 23:23 + W8 예고
- **자유로운 헌신** = 트랙 F (받음)·G W10 (순종은 사랑에서)

오늘 한 문장 — **십일조 = 명시된 청지기. 율법주의 X (강요·저주·자기 의) / 거부 X (은혜 시대 핑계·재정 회피). 받음에서 흐르는 자유로운 헌신.**

### 깊은 자리의 통찰

본문이 가르치는 가장 깊은 자리 — **십일조는 율법주의도, 거부도 아닌 자유로운 청지기직의 자리다.**

창세기 14장 아브라함은 율법이 주어지기 430년 전에 십일조를 드렸습니다. 자발적이었습니다. 멜기세덱(그리스도의 예표)에게 — 자유로운 헌신.

말라기는 십일조 도둑질을 책망하지만 "시험하여 보라" — 자발적 자리로 초청합니다. 마 23:23은 신약에서도 예수님 직접 십일조를 인정하며, 동시에 정의·긍휼·믿음을 강조합니다.

## [마무리]

청지기직을 가르치신 그리스도여,
당신은 아브라함을 통해 율법 이전의 십일조를 보이셨고,
말라기를 통해 청지기직을 회복시키셨으며,
신약에서 "이것도 행하라"고 명령하셨습니다.

평생 율법주의 강박·저주 두려움에 갇혔거나,
"은혜 시대"로 회피한 우리를 받으소서.
자유로운 헌신의 자리,
받음에서 흐르는 청지기직으로 이끄소서.

이미 우리 안에 사시는 그리스도, 멜기세덱의 반차의 대제사장 되시는 분의 이름으로. 아멘.

> *"이것도 행하고 저것도 버리지 말아야 할지니라."* (마 23:23)
