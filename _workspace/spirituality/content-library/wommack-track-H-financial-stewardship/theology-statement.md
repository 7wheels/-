## [2] 트랙 H의 신학적 중심 주장

### 2.1 핵심 명제

> **재정은 청지기의 자리이지 소유주의 자리가 아니다.**
> **번영 복음(재정 = 영적 보상)과 가난 영성(재정 = 악) 양극단 모두 거부한다.**
> **명시된 청지기(십일조·헌금·구제)는 받음에서 흐르는 자유로운 헌신이며, 재정 분별은 사랑이 척도다.**
> **재정 실패는 영적 실패가 아니다. 삭개오 모델 — 정직한 청산과 회복.**

### 2.2 핵심 통찰 6가지

**① 청지기 vs. 소유주 (W1)**
- 시 24:1·마 6:21·눅 16:10-13
- 절대 소유주 = 하나님
- 우리 = 청지기 (오이코노모스)
- 두 주인 X (맘모나 우상화 차단)

**② 양극단 동시 거부 (W2-W3)**
- W2 번영 복음 ★★★★ — 워맥 트랙에서 가장 민감
- W3 가난 영성 ★★★ — 한국 교회 청부론
- 트랙 G W2-W3 (양극단 거부) 패턴 일관

**③ 명시된 청지기 (W4-W5)**
- W4 십일조 — 율법주의 X / 거부 X / 자유로운 헌신
- W5 헌금·구제 — 자원하는 마음 (힐라론)
- 받음에서 흐르는 자리

**④ 재정 분별 (W6-W7)**
- W6 받음과 일하기 — 자력 X / 게으름 X 균형
- W7 빚과 자유 ★★★ — 임상 안전 (도박·자살·R6)
- 트랙 G 분별 원리 일관

**⑤ 사랑이 척도 (W8 ★★★★)**
- 고전 13:3·마 25·요일 3:17
- **5-트랙 통합 완성** (B·E·D·G·H W8)
- 워맥 트랙 시스템 최종 신학적 통합점

**⑥ 회복과 단순한 삶 (W9-W10)**
- W9 삭개오 모델 — 정직한 청산 + 회복
- W10 아우타르케이아 — 자족 + 단순한 삶
- 자기 정죄 X / 강박적 빈곤 X / 과소비 X
