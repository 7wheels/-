### L2 — 교리

> *"권세의 일상은 모든 일을 주 이름으로 — 거룩 / 세속 분리 X. 영적 체험 X / 일상 O. 들음 X / 들음 + 행함 O."*

**거부하는 두 극단:**

❌ **극단 1 — 영적 체험 절대화**
- 권세 = 집회·기도원·체험의 자리
- 특별한 영적 체험·환상·음성 절대화
- 일상 = "그 외의 시간"
- (왜 거부: 골 3:17 "무엇을 하든지" / W4 드라마틱 영적 전쟁 X 일관)

❌ **극단 2 — 일상 환원주의**
- 권세 의식 없는 일상
- 신앙 = 주일·예배 시간만
- "그냥 평범하게"
- (왜 거부: 골 3:17 "주 이름으로" 명시 / 약 1:22 들음만 = 자기 속임)

**5가지 통찰:**
1. 모든 일을 주 이름으로 (골 3:17)
2. 원망·시비 없이 (빌 2:14)
3. 들음 + 행함의 통합 (약 1:22-25)
4. 일상이 영성의 자리 — 거룩/세속 분리 거부
5. 안식이 일상의 호흡 (트랙 F W3 평강 일관)

**핵심 통찰:** **권세는 24/7의 자리.** 식사도·일도·휴식도·관계도 권세. 6주 들음을 일상에 자리하게 하지 않으면 자기 속임 (약 1:22).

**일상의 호흡 (이번 주 매일)**

| 자리 | 호흡 |
|---|---|
| 식사 시작 | "주 이름으로 받습니다" |
| 일 시작 | "주 이름으로 합니다" |
| 관계 시작 | "주 이름으로 만납니다" |
| 휴식 시 | "주 이름으로 안식합니다" |

**핵심:** 영적 체험 X / **일상** O. 들음만 X / **들음 + 행함** O.

**안전장치:**
- 일상의 권세가 율법 X — 받음의 자리에서 흐름
- 자기 정죄 X (계 12:10)
- 카리스마적 순간 부정 X / 절대화도 X
