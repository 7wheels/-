### L2 — 교리

> *"가정·관계의 권세는 권위주의 X / 상호 종속 O. 통제 X / 섬김 O. 일방향 X / 그리스도 안에서의 사랑이 머리 O. **학대 정당화 절대 X / 안전이 우선**."*

**거부하는 두 극단:**

❌ **극단 1 — 권위주의·학대 정당화 (절대 차단)**
- "남편은 머리니까 절대 복종"
- "부모는 권위니까 자녀에게 절대 권한"
- 신체적·정서적·언어적 학대를 "권위" 어법으로 정당화
- 일방적 통제·강압·공포 가정 운영
- "교회·신앙 명분"의 권위 남용
- (왜 절대 차단: 엡 5:21 머리 / 엡 5:25 자신을 주는 사랑 / 막 9:35 종 됨 / 벧전 3:7 귀히 여김 / 본문에 학대 정당화 근거 없음 / **안전이 영적 자세 우선**)

❌ **극단 2 — 권세 무력화·어른어린이**
- "다 평등하니 권위·질서는 없다"
- 가정의 모든 결정이 합의에만 의존
- 부모 권위 무력화 / 자녀 방치
- 거짓 평화 (W6) 자리
- "사랑이라면 직면 X"
- (왜 거부: 본문이 자리·역할 인정 / 거짓 평화는 사랑 X / 자녀 형성을 위한 부모 자리 — 엡 6:4)

**5가지 통찰:**
1. 상호 종속이 머리 (엡 5:21 — 알레로이스, 휘포타소)
2. 머리는 사랑 — 자신을 주는 자리 (엡 5:25)
3. 큼은 종이 됨 (막 9:35 — 디아코노스)
4. 귀히 여김 — 더 연약한 그릇 알고 (벧전 3:7)
5. **학대 정당화 절대 차단** — 안전이 우선

**핵심 통찰:** **사랑 없는 머리됨은 본문의 머리됨이 아니다** (엡 5:25). 권위 어법을 사용하면서 사랑 없으면 그것은 본문이 거부하는 자리. **가정에서의 자세가 영적 자리에 직결** (벧전 3:7 — 기도가 막힘).
