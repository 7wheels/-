## [2쪽 — L1 본문 묵상 + L2 교리]

### L1 — 본문 묵상

**관찰 6개**

1. 마 28:18 "**모든 권세를 내게**"가 사역 권세의 출처에 대해? **엑수시아**.

2. 마 28:19 "**그러므로** 너희는 가서"가 우리 권세 X / 그분의 권세에 참여 O를?

3. 마 28:19 **포류오멘테스**(πορευθέντες, "가는 가운데" 분사형)가 자기 자리 식별 후 머무름을 차단하는 방식?

4. 엡 4:12 다섯 직분의 목적이 "**성도를 갖춤**"(*카테르티스메논*)이라는 것이?

5. 엡 4:16 "**각 지체의 분량대로 역사하여 그 몸을 자라게**"의 자라남(*아욱시스*)이 정적 협력 X / 진취 협력 O를?

6. 행 1:8 동심원 진군(예루살렘 → 유대 → 사마리아 → 땅끝)이 "받은 권능"의 자리에 대해?

### L2 — 교리

> *"사역 영역의 권세는 위임된 권세 — 자기 영웅 X / 그리스도의 몸으로서 O. 직분자만 X / 모든 성도 O. 단독 카리스마 X / 협력의 몸 O. 머무는 자기 자리 X / 가는 자리에서의 자리 O."*

**거부하는 세 극단:**

❌ **극단 1 — 개인 영웅주의**
- 사역 = 카리스마적 개인의 자리
- 단독 명령권자·스타 사역자
- "내가 받은 권세로 내가 행한다"
- 사역 = 직업적 성공·교회 성장 지표
- (왜 거부: 모든 권세가 그분에게 / 트랙 F W6 번영복음 차단 일관)

❌ **극단 2 — 평신도 회피주의**
- "사역은 직분자만의 일"
- "나는 사역자가 아니다"
- 직분자 뒤에 숨음
- 매장된 달란트 (마 25)
- (왜 거부: 다섯 직분의 목적은 모든 성도를 갖춤 / 만인제사장 — 벧전 2:9)

❌ **극단 3 — 사명 위탁·수동적 회피 (사용자 피드백 보강)**
- "그리스도의 몸이니까 다른 사람이 하면 됨"
- "협력 = 가만히 자기 자리만"
- 자기 자리 식별 → 그 자리에 머물러 멈춤
- "가서"의 진취적 명령을 회피·위탁
- (왜 거부: 마 28:19 *포류오멘테스* / 행 1:8 동심원 진군 / 엡 4:16 *아욱시스* 자라남 / 트랙 B W4 수동적 회피 거부 일관)

**6가지 통찰:**
1. 위임된 권세 (마 28:18, 트랙 F W7·B W4 일관)
2. 그리스도의 몸으로서 (엡 4 — 소마)
3. 다섯 직분의 협력 (엡 4:11-13)
4. 성령의 능력 — 받는 능력 (행 1:8)
5. **진취적 사명** — *포류오멘테스* (가는 가운데), 동심원 진군, 자라나는 몸. 머무름 X / 진취 O. 위탁·회피 X / 자기 가는 자리 O
6. 사랑이 척도 (W6 예고)

**핵심 통찰 1:** **자기 자리는 몸 전체에서만 의미가 있다.** 손은 발이 될 수 없고 발은 손이 될 수 없음 (고전 12).

**핵심 통찰 2:** **자기 자리는 정적 자리매김 X / 가는 자리 O.** "내 자리는 가정이다"가 멈춤의 자리가 아니라 가정에서 가는 자리(증인됨·복음 진군·일상의 능동성). *포류오멘테스* — 가는 가운데 식별.
