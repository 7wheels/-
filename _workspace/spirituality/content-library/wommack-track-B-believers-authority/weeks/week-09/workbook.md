### L2 — 교리

> *"위기는 권세 없음의 증명 X / 더 깊은 권세의 자리. 회피 X / 통과 O. 단독 X / 함께 가시는 그리스도 안에서. 신비 사라짐 X / 골짜기 가운데 함께하심."*

**거부하는 두 극단:**

❌ **극단 1 — 위기 = 권세 없음**
- "위기를 만난다 = 권세 받지 않은 증거"
- 의심·낙심·자기 정죄
- "내 믿음이 부족해서"
- 8주 들음 무력화
- (왜 거부: 약 1:2 / 벧전 4:12 / 시 23:4 / 그리스도 자신이 시험 받으심 / 트랙 F W5 일관)

❌ **극단 2 — 위기 회피 신비주의**
- "위기는 다 사탄. 기도하면 사라진다"
- 권세 어법으로 환경 통제 추구
- 위기 자체 부정·회피
- 의학·전문가·실제적 도움 거부
- (왜 거부: 약 1:2-4 통과 / 벧전 4:13 참여 / 시 23:4 다님 / 트랙 B W4 일관)

**5가지 통찰:**
1. 시험은 권세 없음 X / 검증의 자리 (약 1:3 도키미온)
2. 통과하면서 더 깊이 — 휘페르니카오멘 (롬 8:37, 트랙 B W3 일관)
3. 함께 가시는 그리스도 (벧전 4:13·시 23:4)
4. 이상히 여기지 말라 — 시험은 정상 자리 (벧전 4:12)
5. 위기 자체가 권세의 자리 — 회피한 자리에서는 도달 불가

**핵심 통찰:** **위기는 권세를 검증하는 자리이지 권세 없음의 증명이 아니다.** 8주 들음의 자리가 위기 만나면 흔들리는 것은 자연스러움. 흔들림 한가운데서 함께하시는 그분이 진짜 권세.
