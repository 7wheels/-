# 콘텐츠 템플릿 — 회당 5층 구조

> 발행: 2026-05-03 | 작성: 영성 (마태 골격)
> Stage 0.4 — 모든 트랙의 1주(회당) 표준 구조

---

## 0. 회당이란

1 트랙 = 12주 = 12 회당. 1 회당 = **(설교 1편 + 교재 1주분 + 슬라이드 1세트 + 소그룹 1회)** 의 4종 산출물.

회당은 **5개 층(layer)** 으로 구성된다. 4종 산출물은 모두 이 5층을 따른다 — 다만 강조와 분량이 다를 뿐.

---

## 1. 5층 구조 정의

| 층 | 이름 | 핵심 질문 | 비중 |
|----|------|---------|------|
| **L1** | 본문 (Scripture) | 성경은 무엇이라 말하는가 | 20% |
| **L2** | 교리 (Doctrine) | 이것은 어떤 신학적 진리인가 | 15% |
| **L3** | 마음공부 (Inner Work) | 내 안에서 무엇이 일어나는가 | 20% |
| **L4** | 실천 (Practice) | 이번 주에 무엇을 할 것인가 | 25% |
| **L5** | 공동체 적용 (Community) | 우리가 함께 어떻게 살 것인가 | 20% |

비중은 표준값. 트랙별·주차별로 ±10% 조정 허용.

## 2. 산출물별 5층 적용

### 2-1. 설교문 (`sermon.md`) — 30~40분 분량 / 4,000자 기준

```
[도입 — 일상의 한 장면 또는 질문] 5분 / 500자
L1 본문 — 본문 낭독·맥락 / 강해 5~7분 / 800자
L2 교리 — 통합 신학 진술서 명제와 연결 / 5분 / 600자
L3 마음공부 — 본문이 마음에서 작동하는 방식 / 5~7분 / 700자
L4 실천 — 이번 주 실천 1가지 (구체적·측정 가능) / 5분 / 500자
L5 공동체 — 소그룹·일상 관계에서의 적용 / 3분 / 400자
[마무리 — 기도·축복] 3분 / 300자
[부록] 핵심 구절·찬송·소그룹 질문 5개
```

### 2-2. 교재 (`workbook.md`) — 4쪽 기준 (소그룹 진행 중 사용)

```
1쪽 — 표지·금주 본문·핵심 메시지 한 문장
2쪽 — L1 본문 묵상 (낭독·관찰·해석 질문 5개)
       L2 교리 한 단락 (통합 신학 진술서 인용)
3쪽 — L3 마음공부 워크시트 (자기성찰 질문 5개)
       L4 실천 카드 (이번 주 실천·체크리스트)
4쪽 — L5 소그룹 토의 질문 5개
       다음 주 예고·기도제목
```

### 2-3. 슬라이드 (`slides.md`) — 25매 기준

```
01 표지: 트랙·주차·금주 한 문장
02 도입: 일상 장면 or 질문
03 본문 낭독 (L1)
04-06 본문 강해 3매 (L1)
07 교리 연결 (L2 — 통합 신학 진술서 명제 #N)
08-09 교리 풀이 2매 (L2)
10 전환: 본문 → 마음
11-13 마음공부 3매 (L3)
14 자기성찰 질문 1개
15-17 실천 3매 (L4)
18 실천 카드 (이번 주 약속)
19-20 공동체 적용 2매 (L5)
21 소그룹 질문 1개
22 다음 주 예고
23 핵심 구절 다시
24 기도
25 축복
```

### 2-4. 소그룹 (`small-group.md`) — 90분 기준

```
00:00-10:00  환영·체크인 (베드로 매뉴얼 따름)
10:00-15:00  L1 본문 낭독 (렉시오 디비나 1회독)
15:00-25:00  L1 본문 묵상 질문 (교재 2쪽)
25:00-35:00  L2 교리 한 단락 함께 읽고 정리
35:00-50:00  L3 마음공부 워크시트 (개인 작성 + 짝 나눔)
50:00-65:00  L4 실천 — 이번 주 실천 약속 작성 + 짝과 공유
65:00-80:00  L5 공동체 토의 (5개 질문 중 2~3개)
80:00-85:00  실천 프로토콜 1회 (빌립 매뉴얼 — 호흡기도 등)
85:00-90:00  기도·축복·다음 주 예고
```

## 3. 5층별 작성 가이드

### L1 본문
- **선택 원칙:** 트랙 주제와 직결되는 핵심 본문 1~2개. 보조 본문 최대 3개
- **낭독 표시:** 본문 전체를 인용 블록으로 표기
- **강해 깊이:** 헬라어·히브리어 1~2개 핵심 단어만 (과도한 원어 풀이 금지)
- **금지:** 본문에 없는 의미 끼워 넣기, 알레고리 남발

### L2 교리
- **연결 의무:** 통합 신학 진술서(`unified-theology.md`) 12 명제 중 **반드시 1개 이상** 명시 인용
- **분량:** 한 단락 (300~600자). 신학 강의가 아니라 본문과 명제의 다리
- **금지:** 진술서 외 새 신학 주장. 충돌 시 도마 검토 필수

### L3 마음공부
- **3중 근거:** 성경 + 영성전통 + 신경과학·심리학(보조)
- **자기성찰 질문:** 5개 표준
  1. 본문이 내 어떤 부분을 만지는가
  2. 저항이 일어나는 지점은 어디인가
  3. 이미 익숙한 사고 패턴은 무엇인가
  4. 새로 받아들이고 싶은 진실은 무엇인가
  5. 이번 주 알아차림으로 가져갈 것은 무엇인가
- **금지:** 어휘 변환표 위반 (방화벽 3-1 자동 반려)

### L4 실천
- **SMART 기준:** 구체적(Specific)·측정가능(Measurable)·달성가능(Achievable)·관련성(Relevant)·기한(Time-bound)
- **분량:** 1주에 1가지 핵심 실천 + 매일 5분 미니 실천
- **실천 종류:** 호흡기도 / 렉시오 디비나 / 자기관찰 일지 / 무의식 행동교정 프로토콜 (빌립 매뉴얼 참조)

### L5 공동체 적용
- **관계 차원:** 가족·소그룹·교회·일상 관계 중 1개 이상
- **소그룹 질문 5개 표준:**
  1. 본문에서 공동체로서 우리에게 주는 메시지는
  2. 이번 주 공동체에 함께 가져가고 싶은 알아차림은
  3. 우리 중 누가 이 메시지로 격려받을 수 있는가
  4. 이번 주 함께 기도할 제목은
  5. 다음 주 만남 전 함께 실천할 것은

---

## 4. 작성·발행 흐름

```
1. 마태가 회당 골격(5층 분배·핵심 본문) 작성
2. 요한이 L2 교리 단락 작성·검토
3. 빌립이 L3·L4 실천 부분 검수
4. 베드로가 L5 공동체 적용 검수
5. 안드레가 4종 산출물(설교·교재·슬라이드·소그룹) 콘텐츠 변환
6. 도마가 자가 점검 체크리스트 적용 (방화벽 3장)
7. 영성이 통합 검수 → 발행
```

## 5. 품질 기준 (회당 발행 전 통과)

- [ ] 5층이 모두 채워졌는가
- [ ] L2가 통합 신학 진술서 명제와 명시적으로 연결되는가
- [ ] L4 실천이 SMART 기준을 통과하는가
- [ ] 4종 산출물(설교·교재·슬라이드·소그룹)이 일관되는가
- [ ] 어휘 변환표 위반이 없는가 (방화벽 3-1)
- [ ] 3중 근거가 마음공부·행동교정에 적용되었는가
