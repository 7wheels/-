# 핵심 용어 사전

> 발행: 2026-05-03 | 작성: 영성 (마태·요한 골격)
> Stage 0.4 — 모든 트랙·회당에서 일관되게 사용할 핵심 용어 정의
> **모든 산출물은 이 사전의 정의를 따라야 한다. 다른 정의가 필요하면 이 사전에 먼저 추가한다.**

---

## 0. 사용 원칙

1. 본 사전 외 정의로 핵심 용어를 사용할 수 없다
2. 새 용어는 마태가 초안 → 요한 신학 검토 → 도마 어휘 점검 → 영성 승인 후 추가
3. 설교·교재·슬라이드·소그룹 자료 모두 본 사전을 참조한다
4. 해당 용어가 처음 등장하는 회당에서 정의를 명시 인용한다

각 항목 형식: **정의 / 성경 본문 / 사용 예 / 주의·금지**

## A. 신학 핵심 용어

### 안식 (Rest)
- **정의:** 그리스도 안에서 누리는 하나님의 영원한 안식. 노력의 멈춤이 아니라 받음의 자세.
- **본문:** 히 4:9-11 / 마 11:28-30
- **사용 예:** "참 안식은 그리스도 안에 있다."
- **주의:** 휴식·여가와 동의어로 환원하지 않는다.

### 안식일 (Sabbath)
- **정의:** 그리스도 안의 안식의 표지·실천으로서 일곱째 날.
- **본문:** 출 20:8-11 / 히 4:9-11 / 롬 14:5-6
- **사용 예:** "안식일은 안식의 본질을 기념하고 실천하는 날이다."
- **금지:** "안식일 준수가 구원의 조건이다" (율법주의). 또는 "안식일은 폐지되었다" (반대 극단).

### 은혜 (Grace)
- **정의:** 행위와 무관하게 하나님이 공급하시는 모든 것. 받는 것.
- **본문:** 엡 2:8-9 / 롬 5:17 / 요 1:16
- **사용 예:** "은혜는 공급, 믿음은 통로."
- **주의:** "값싼 은혜"가 되지 않도록 변화·열매와 분리하지 않는다.

### 믿음 (Faith)
- **정의:** 하나님의 공급(은혜)을 받는 통로. 의지가 아닌 신뢰.
- **본문:** 히 11:1 / 막 11:24 / 엡 2:8
- **사용 예:** "믿음은 수도꼭지다 — 우물의 물을 만들지는 않지만 흘러나오게 한다."
- **금지:** 믿음을 능력의 원천으로 절대화 (Word of Faith 위험).

### 정체성 (Identity)
- **정의:** 그리스도와 연합한 자가 누구인가에 대한 성경적 진술. "나는 ~이다"의 그리스도 안 선언.
- **본문:** 갈 2:20 / 골 1:27 / 고후 5:17
- **사용 예:** "내 정체성은 내가 만든 것이 아니라 그리스도 안에서 받은 것이다."
- **금지:** 자아 단독 선언으로의 I AM (자아 신격화).

### 권세 (Authority)
- **정의:** 그리스도께서 부활 후 받으셔서 우리에게 위임하신 영적 다스림.
- **본문:** 마 28:18 / 눅 10:19 / 엡 1:19-23
- **사용 예:** "권세는 이미 주어졌다 — 사용하지 않으면 잠들어 있다."
- **금지:** 권세를 자기 능력으로 환원 (마술적 사고).

### 영(靈) / Spirit
- **정의:** 인간의 가장 깊은 자리. 거듭난 사람의 영은 이미 완전(고후 5:17). 하나님과 직접 소통.
- **본문:** 살전 5:23 / 요 4:24 / 고전 6:17
- **사용 예:** "거듭난 영은 더 갱신할 필요가 없다 — 갱신할 곳은 혼이다."

### 혼(魂) / Soul
- **정의:** 마음·뜻·감정. 갱신이 일어나는 자리(롬 12:2).
- **본문:** 롬 12:2 / 살전 5:23 / 시 23:3
- **사용 예:** "혼이 영을 따라가게 하라."

### 몸(身) / Body
- **정의:** 영혼이 드러나는 그릇. 성령의 전(고전 6:19).
- **본문:** 고전 6:19 / 롬 12:1 / 롬 8:23
- **사용 예:** "몸은 영혼의 마지막에 따라온다."

### 그리스도 내주 / Indwelling Christ
- **정의:** 그리스도께서 거듭난 자 안에 실제로 사신다는 사실(존재론적 진리).
- **본문:** 갈 2:20 / 골 1:27 / 요 14:20
- **사용 예:** "내가 그리스도를 모방하는 것이 아니라, 내 안의 그리스도가 사시는 것이다."

### 남은자손 / Remnant
- **정의:** 그리스도의 내주의 증거를 사는 자. 계명을 지키며 예수의 증거를 가진 자.
- **본문:** 계 12:17 / 계 14:12
- **사용 예:** "남은자손은 율법 준수자가 아니라 그리스도 내주의 증거를 사는 자다."
- **금지:** 율법주의적 해석 / 종교적 우월감.

### 마음의 갱신 / Renewing the Mind
- **정의:** 혼(생각·뜻·감정)이 그리스도의 진리로 새로워지는 과정.
- **본문:** 롬 12:2 / 엡 4:23 / 빌 4:8
- **사용 예:** "변화는 의지의 노력이 아니라 마음의 갱신에서 흘러나온다."

### 받음 (Receive)
- **정의:** 이미 주어진 것을 받아들이는 영적 자세. 워맥 신학의 중심 동사.
- **본문:** 요 1:12 / 막 11:24 / 롬 5:17
- **사용 예:** "구하지 말고 받으라."
- **주의:** 수동적 무위와 구분 — 받음은 능동적 신뢰.

## B. 영성 실천 용어

### 묵상 (Meditation, Christian)
- **정의:** 성경 본문이나 그리스도의 진리를 마음에 깊이 머무르게 하는 영적 실천.
- **본문:** 시 1:2 / 시 119:97
- **사용 예:** "묵상은 비움이 아니라 채움이다."
- **금지:** 단독 '명상' 사용 (동양종교 연상).

### 관상기도 (Contemplative Prayer)
- **정의:** 말없이 하나님 앞에 머무는 기도. 들음과 임재의 기도.
- **본문:** 시 46:10 / 합 2:20
- **전통:** 향심기도(Centering Prayer), 토마스 키팅
- **사용 예:** "관상기도는 하나님께 말하는 것을 멈추고 하나님과 함께 있는 것이다."

### 렉시오 디비나 (Lectio Divina)
- **정의:** 성경 본문을 4단계(읽기·묵상·기도·관상)로 듣는 베네딕트 영성 전통.
- **사용 예:** "렉시오 디비나는 본문이 우리를 읽게 하는 방식이다."

### 예수기도 (Jesus Prayer)
- **정의:** "주 예수 그리스도, 하나님의 아들이시여, 이 죄인에게 자비를 베푸소서"의 호흡과 결합된 반복 기도.
- **전통:** 동방 정교회 헤시카즘
- **사용 예:** "예수기도는 호흡마다 그분의 이름을 부르는 것이다."

### 호흡기도 (Breath Prayer)
- **정의:** 호흡과 짧은 기도문을 결합한 실천. 성령(루아흐)의 호흡과 연결.
- **본문:** 창 2:7 / 요 20:22
- **사용 예:** "들숨에 '주여', 날숨에 '내가 여기 있나이다'."

### 마음챙김 (Christian Mindfulness)
- **정의:** 그리스도의 임재 안에서 현재 순간을 알아차리는 영적 자세. 동양 마음챙김의 기독교적 전유.
- **본문:** 시 46:10 / 마 6:34
- **사용 예:** "그리스도 안의 마음챙김은 자아의 알아차림이 아니라 임재의 알아차림이다."
- **금지:** 단순한 'Mindfulness' 단독 사용 (동양종교 연상). 항상 '기독교 마음챙김' 또는 '그리스도 안의 마음챙김'.

### 무의식 (Unconscious)
- **정의:** 하나님이 인간 마음에 두신, 의식 표면 아래 작동하는 사고·감정·습관의 자리.
- **본문:** 잠 4:23 / 시 51:6
- **사용 예:** "마음의 갱신은 의식뿐 아니라 무의식의 차원에서도 일어난다."
- **금지:** 무의식을 신비한 능력의 원천으로 절대화. 신경과학은 보조 설명.

### 행동교정 (Behavior Renewal)
- **정의:** 마음의 갱신이 무의식·습관·신경회로 차원에서 작동하여 행동이 자연스럽게 변화하는 과정.
- **본문:** 롬 12:2 / 엡 4:22-24
- **사용 예:** "노력 없는 변화는 행동을 직접 강제하는 것이 아니라 마음의 뿌리를 갱신하는 것이다."
- **금지:** '자기 최면' '서브리미널' 단어 사용 (뉴에이지 연상).

### 알아차림 (Awareness)
- **정의:** 마음에서 일어나는 일을 비판단적으로 관찰하는 자세. 끌어당김을 대신하는 우리 어휘.
- **사용 예:** "끌어당기는 것이 아니라 알아차리는 것이다."

## C. 공동체 용어

### 회당 (Session / Week)
- **정의:** 1 트랙의 1주분. 설교+교재+슬라이드+소그룹의 4종 산출물을 묶은 단위.

### 트랙 (Track)
- **정의:** 워맥 저서 1권을 12주에 걸쳐 풀어내는 사역 단위. 설교 + 성경공부 프로그램.

### 소그룹 (Small Group / Cell)
- **정의:** 5~12명의 구성원이 함께 트랙을 진행하는 학습·교제·기도의 공동체 단위.

### 영적 동반자 (Spiritual Companion)
- **정의:** 1:1로 영적 여정을 함께 나누는 짝. 영적 지도자와 다름 — 동등한 위치의 동반.

### 리트릿 (Retreat)
- **정의:** 일상에서 분리되어 침묵·기도·묵상에 집중하는 시간.

### 통합 신학 진술서 (Unified Theology Statement)
- **정의:** 공동체의 신학적 헌법. `unified-theology.md`에 기록된 12 명제와 충돌 매뉴얼.

### 정통 방화벽 (Orthodoxy Firewall)
- **정의:** 이단 시비에 대한 사역 보안 정책. `orthodoxy-firewall.md`.
