# 프로그램 포트폴리오 — 워맥 다트랙 영성공동체 사역 지도

> 발행: 2026-05-03 | 작성: 영성 (오케스트레이터)
> 이 문서는 영성공동체 전체 사역의 **마스터 지도**다.
> 모든 트랙·모든 메타 문서·모든 회당 산출물은 이 지도 위에 얹힌다.

## 1. 공동체 비전 한 문장

> **재림교회 기반 남은자손 영성공동체** — 성경적 마음챙김 + 관상기도 + 무의식 기반 행동교정을 통합한, 그리스도 내주(內住)의 살아있는 증거 공동체.

> "그리스도께서 내 안에 사신다 — 나는 비움으로 사랑이 되고, 안식으로 창조하며, 내어드림으로 자유롭다." (갈 2:20 + 골 1:27 + 히 4:9)

남은자손의 정의: **"하나님의 계명을 지키며 예수의 증거를 가진 자"** (계 12:17). 율법주의가 아니라 **그리스도 내주의 증거를 사는 자들**.

## 3. 트랙 지도 (현재 8 트랙 + 확장 가능)

| 코드 | 트랙명 | 워맥 저서 | 핵심 메시지 (한 줄) | 단계 |
|------|--------|---------|------------------|------|
| **A** | 영혼몸 | Spirit, Soul & Body | 인간은 영·혼·몸 — 거듭난 영은 이미 완전, 갱신할 곳은 혼이다 | 토대 |
| **F** | 당신은 이미 가졌습니다 | You've Already Got It | 구하지 말고 받으라 — 십자가에서 이미 모든 것이 주어졌다 | 정체성 |
| **C** | 은혜와 믿음의 균형 | Living in the Balance of Grace and Faith | 은혜는 공급, 믿음은 수도꼭지 — 행위가 아닌 받음 | 작동 원리 |
| **B** | 믿는자의 권세 | The Believer's Authority | 권세는 이미 주어졌다 — 사용하지 않으면 없는 것과 같다 | 적용 |
| **E** | 노력없이 오는 변화 | Effortless Change | 변화는 의지가 아니라 마음의 갱신에서 흘러나온다 | 성화 |
| **D** | 하나님을 제한하지 마라 | Don't Limit God | 하나님 능력은 우리의 기대만큼 흐른다 | 확장 |
| **G** | 하나님의 뜻 | Discover/Follow/Fulfill God's Will | 뜻은 멀리 있지 않다 — 그리스도 내주 안에 이미 있다 | 소명 |
| **H** | 재정의 청지기직분 | Financial Stewardship | 돈은 우상이거나 도구다 — 청지기는 도구로 쓴다 | 실천 |

확장 후보: 치유 / 영적 전쟁 / 가족 / 결혼 / 자녀 양육 / 죽음과 영원

## 4. 추천 학습 여정 (스토리 아크)

```
A 영혼몸 (인간이 누구인가)
   │  "내 영은 이미 완전하다"
   ▼
F 이미 가졌습니다 (정체성의 수용)
   │  "구하지 말고 받으라"
   ▼
C 은혜와 믿음 (어떻게 받는가)
   │  "은혜는 공급, 믿음은 수도꼭지"
   ▼
B 믿는자의 권세 (받은 자의 행함)
   │  "권세는 사용할 때 살아난다"
   ▼
E 노력없이 오는 변화 (혼의 갱신)
   │  "마음이 새로워지면 행동은 따라온다"
   ▼
D 하나님을 제한하지 마라 (기대의 확장)
   │  "기대의 그릇만큼 흐른다"
   ▼
G 하나님의 뜻 (소명의 발견)
   │  "뜻은 내주하시는 그리스도 안에 있다"
   ▼
H 재정 청지기 (삶의 통합)
      "도구로 살면, 돈도 예배가 된다"
```

**왜 이 순서인가**
1. 워맥 신학의 빌딩 블록 순서 — 영혼몸 인간론 없이는 정체성·은혜가 떠다님
2. SDA 영성형성 곡선 — 정체성 → 은혜 → 사명 → 실천
3. 점진적 심화 — 추상(존재) → 구체(돈)
4. 첫 트랙은 **A 영혼몸** — 모든 트랙이 인용하는 인간론, 데모 슬라이드 보유

| C 은혜·믿음 | (1)은혜·믿음 정의 → (2-4)불균형의 위험 → (5-9)성경 인물별 사례 → (10-12)일상의 균형 |
