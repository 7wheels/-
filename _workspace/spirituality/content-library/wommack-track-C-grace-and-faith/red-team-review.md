## 5. 트랙 B 진입 전 권고

트랙 C의 학습을 트랙 B에 가져갈 때 도마 강조 5가지:

1. **두 극단 동시 거부 패턴 — 트랙 B에서도** 권세 절대화 + 권세 무력화 양쪽 거부 (트랙 F W7 일관 + 트랙 C W3 패턴 적용).

2. **자기 정죄 = 고소자 음성 어법 일관** — 트랙 B에서도 7회째 사용. 영성 공동체 표준 어법.

3. **호흡 같은 순환 → 권세의 행함도 호흡** 트랙 B에서 권세 행사를 호흡 같은 순환으로 풀이.

4. **5인물 패턴은 트랙 B에서 사도행전 인물(베드로·바울·스데반·빌립)** 로 확장 가능.

5. **현재 메인 라인 약 13,000 + 트랙 B 약 10,000 = 23,000.** 임계 30,000 이내. 트랙 B는 메인에서 진행, 종료 시 마이그레이션.
