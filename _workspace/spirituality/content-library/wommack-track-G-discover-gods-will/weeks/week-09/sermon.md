# 트랙 G · Week 9 — 뜻 분별 실패: 회복과 인내
## (수네르게이 에이스 아가톤 — 롬 8:28 / 요 21:15-17 / 잠 24:16)

> 본문: 로마서 8:28 / 요한복음 21:15-17 / 잠언 24:16
> 분량: 약 4,000자 / 30~40분
> 도마 검토 ★★★ — 분별 실패 자기 정죄 + "모든 일 = 좋음" 오용 차단

## [도입]

W8에서 사랑이 척도(4-트랙 통합)를 봤습니다. 오늘은 뼈아픈 현실 — **뜻 분별에 실패했을 때.**

8주 동안 분별을 배웠지만 실패합니다. 자의적 분별로 결정 → 후회. 두 극단(W2-W3) 패턴이 다시 나타남. W6-W7 척도 무시 → 잘못된 길. 사랑 없이 분별 → 관계 깨짐.

이때 두 함정이 있습니다.

첫째 — **자기 정죄·고소자 음성:** "나는 분별 못해", "또 실패했어", "하나님이 실망하셨을 것" — 계 12:10 고소자 음성.

둘째 — **거짓 위로·오용:** "모든 일이 합력하여 선을 이루니까 괜찮아" (롬 8:28 오용), "어차피 다 하나님의 뜻" (W2 운명주의 변형).

성경은 분별 실패의 자리에서 **회복과 인내**를 가르칩니다. 베드로의 부인 후 회복, 잠언의 "일곱 번 넘어져도 다시 일어남."

## [L1 — 본문]

### 모든 것이 합력하여 선을 이루느니라

> "우리가 알거니와 하나님을 사랑하는 자 곧 그의 뜻대로 부르심을 입은 자들에게는 **모든 것이 합력하여 선을 이루느니라**." (롬 8:28)

분별 실패 안에서의 신실하심.

**핵심 1 — "모든 것이 합력하여 선을 이루느니라"** *판타 수네르게이 에이스 아가톤*(πάντα συνεργεῖ εἰς ἀγαθόν)
- *수네르게이* — 함께 일하다·협력하다
- 실패도 포함 (분별 실패까지)
- 하나님이 합력시키심 — 실패가 그 자체로 선 X

**핵심 2 — "하나님을 사랑하는 자 ... 그의 뜻대로 부르심을 입은 자들에게는"**
- 조건 명시 — 무조건 X
- 사랑·부르심 안에서 (W8 사랑이 척도 일관)
- 운명주의 X / 관계 안에서

**핵심 3 — 오용 차단**
- "실패도 선" X — 실패는 실패
- "어차피 다 좋은 결과" X — 운명주의 (W2)
- 학대·악·죄도 정당화 X (B W8·E W7·D W9 일관)
- 합력시키심 = 회복과 새로운 길

### 베드로의 회복

> "조반 먹은 후에 예수께서 시몬 베드로에게 이르시되 **요한의 아들 시몬아 네가 이 사람들보다 나를 더 사랑하느냐** ... 베드로가 ... 근심하여 이르되 주님 모든 것을 아시오매 내가 주님을 사랑하는 줄을 주님께서 아시나이다 ... 이르시되 **내 양을 먹이라**." (요 21:15-17)

분별 실패 후 회복의 모델.

**핵심 1 — 분별 실패의 모델**
- 베드로 — 자기 의지로 "주를 위해 죽겠다" (W3 일관, 마 26:35)
- 세 번 부인 — 분별 실패의 극점
- 그러나 끝이 아님

**핵심 2 — 세 번의 질문**
- 부인 세 번 → 회복의 질문 세 번
- *아가파스 메?·필레이스 메?* — 사랑 검증 (W8 사랑이 척도 일관)
- 분별 능력 X / 사랑의 자리 회복

**핵심 3 — "내 양을 먹이라"**
- 회복 = 새로운 부르심
- 실패가 사역의 끝 X
- 회복 + 책임 부여

### 일곱 번 넘어질지라도 다시 일어나려니와

> "**대저 의인은 일곱 번 넘어질지라도 다시 일어나려니와** 악인은 재앙으로 말미암아 엎드러지느니라." (잠 24:16)

분별 실패 패턴의 정상화.

**핵심 1 — "일곱 번 넘어질지라도"** *셰바 이폴*(שֶׁבַע יִפּוֹל)
- 한 번 X / 일곱 번 (반복적·완전한 실패)
- 의인도 넘어짐 — 정상
- W2 운명주의 ≠ 의인의 일반 패턴

**핵심 2 — "다시 일어나려니와"** *바캄*(וָקָם)
- 자기 정죄 X / 다시 일어남
- 회복이 의인의 표지 (실패 없음 X)
- 자기 의 자랑 차단 (의인 = 다시 일어나는 자)

**핵심 3 — 트랙 일관**
- 트랙 D W4 (좌절·실패 안에서 신실)·B W11 (이미·아직) 일관
- 자기 정죄 X — 다시 일어남

세 본문이 함께 가르칩니다 — **분별 실패는 끝 X. 합력시키시는 하나님 + 회복의 자리 + 다시 일어남.**

## [L2 — 교리]

이 자리에서도 두 극단을 거부합니다.

### 거부하는 극단 1 — 분별 실패 자기 정죄 (고소자 음성)

**잘못된 주장:**
- "나는 분별 못해 — 영적 실패자"
- "또 실패했으니까 하나님이 실망"
- "분별 못하면 사랑받을 자격 X"
- 계 12:10 고소자 음성 패턴

**왜 거부하는가:**
- 잠 24:16 — 의인도 일곱 번 넘어짐 (실패가 의인의 일부)
- 요 21:15-17 — 베드로 회복 모델 (분별 실패도 회복)
- 롬 8:1 — 정죄함이 없음
- 트랙 B·E·D·G 누적 — 자기 정죄 X (계 12:10)

### 거부하는 극단 2 — "모든 것이 선" 오용 (거짓 위로)

**잘못된 주장:**
- "어차피 다 하나님의 뜻이니까 괜찮아"
- 롬 8:28 오용 — "실패도 선"
- W2 운명주의 변형
- 책임 회피·죄 정당화

**왜 거부하는가:**
- 롬 8:28 — "합력하여 선" (실패 자체가 선 X)
- "사랑하는 자 ... 부르심을 입은 자들" 조건 명시
- 학대·죄 정당화 X (B W8·E W7·D W9 일관)
- W3 자기 의지 정직 + 순복 (Gethsemane)

### 우리의 자리 — 회복과 인내 (합력시키시는 신실하심)

> *"분별 실패 = 자기 정죄 X / 거짓 위로 X. 합력시키시는 하나님 + 회복의 자리 + 다시 일어남."*

**5가지 통찰:**

1. **수네르게이 에이스 아가톤** — 합력하여 선을 이루심 (실패도 합력의 자리)
2. **조건 명시** — "사랑하는 자 ... 부르심을 입은 자들" (운명주의 X)
3. **베드로 모델** — 부인 → 회복 → 새로운 부르심 ("내 양을 먹이라")
4. **사랑의 자리 회복** — 분별 능력 X / 사랑 검증 (요 21, W8 일관)
5. **일곱 번 넘어져도 다시** — 자기 정죄 X / 회복이 의인의 표지

### 트랙 일관

- **분별 실패 + 회복** = 트랙 B W4·D W4·E W6 일관
- **합력시키시는 신실** = 트랙 D W5 (카이로스·하나님의 때) 일관
- **자기 정죄 X (계 12:10)** = 8-트랙 누적 안전장치
- **회복의 사랑 검증** = W8 사랑이 척도 일관
- **W2 운명주의 차단** = "모든 것이 선" 오용 거부

오늘 한 문장 — **분별 실패 = 자기 정죄 X / 거짓 위로 X. 합력시키시는 하나님 + 회복 + 다시 일어남.**

## [L3 — 마음공부]

자기 안의 분별 실패 대응 자세를 정직하게 봅니다.

### 자기 진단 — 3자세

**1. 분별 실패 자기 정죄형**

**2. 거짓 위로·오용형**

- 롬 8:28 오용 ("실패도 선")
- 책임 회피
- W2 운명주의 변형

**3. 회복과 인내형 (이상)**
- 합력시키시는 신실 신뢰
- 자기 정죄 X
- 베드로 모델 — 사랑의 자리 회복
- 다시 일어남 (잠 24:16)

### 깊은 자리의 통찰

본문이 가르치는 가장 깊은 자리 — **분별 실패는 끝이 아니다. 합력시키시는 하나님 + 회복 + 다시 일어남.**

베드로는 분별 실패의 극점에 갔습니다 — 세 번 부인. 그러나 거기서 끝나지 않았습니다. 예수님이 찾아오셨고, 사랑의 자리를 회복시키셨고, 새로운 부르심을 주셨습니다.

자기 정죄는 회복을 방해합니다. "모든 일이 선"이라는 거짓 위로도 회복을 방해합니다. **자기 정죄 X + 거짓 위로 X = 정직한 인정 + 회복의 자리.**
