### L2 — 교리

> *"분별 실패 = 자기 정죄 X / 거짓 위로 X. 합력시키시는 하나님 + 회복 + 다시 일어남."*

**거부하는 두 극단:**

❌ **극단 1 — 분별 실패 자기 정죄 (고소자 음성)**
- "나는 분별 못해 — 영적 실패자"
- "또 실패했으니까 하나님이 실망"
- 계 12:10 고소자 음성 패턴
- (왜 거부: 잠 24:16 의인도 일곱 번 넘어짐 / 요 21:15-17 베드로 회복 / 롬 8:1 정죄 없음 / 8-트랙 누적 안전장치)

❌ **극단 2 — "모든 것이 선" 오용 (거짓 위로)**
- "어차피 다 하나님의 뜻이니까 괜찮아"
- 롬 8:28 오용 — "실패도 선"
- W2 운명주의 변형
- 책임 회피·죄 정당화
- (왜 거부: 롬 8:28 "합력하여 선" 조건 명시 / 학대·죄 정당화 X / B W8·E W7·D W9 일관)

**5가지 통찰:**
1. 수네르게이 에이스 아가톤 — 합력하여 선 (실패 자체 X)
2. 조건 명시 — "사랑하는 자 ... 부르심을 입은 자들" (운명주의 X)
3. 베드로 모델 — 부인 → 회복 → 새로운 부르심
4. 사랑의 자리 회복 — 분별 능력 X / 사랑 검증 (W8 일관)
5. 일곱 번 넘어져도 다시 — 자기 정죄 X / 회복이 의인의 표지

**핵심 통찰:** **분별 실패는 끝이 아니다.** 베드로 — 세 번 부인 → 세 번 회복 질문 → "내 양을 먹이라." 자기 정죄는 회복을 방해. 거짓 위로도 회복을 방해. **자기 정죄 X + 거짓 위로 X = 정직한 인정 + 회복의 자리.**

⚠ **롬 8:28 오용 차단.** "합력하여 선" ≠ "실패·악·죄 자체가 선." 학대·악도 정당화 X (B W8·E W7·D W9 일관).
