### L2 — 교리

> *"개별적 뜻 분별 = 3척도 (정통·사랑·열매). 자의적 분별 X / 분별 포기 X. 말씀·사랑·열매로 검증."*

**거부하는 두 극단:**

❌ **극단 1 — 자의적 분별**
- "하나님이 내게 직접 말씀하셨다" — 검증 없이
- 자기 욕망·감정을 뜻으로 합리화
- 주관적 직감을 최종 권위로
- (왜 거부: 롬 12:2 도키마제인 = 검증 과정 / 렘 17:9 / W2 신비주의 일관)

❌ **극단 2 — 분별 포기 (맹목적 순종)**
- "어차피 알 수 없으니 그냥 순종"
- 권위·감정·상황에 맹목적 따름
- 분별 책임 회피
- (왜 거부: 롬 12:2 "분별하도록 하라" 책임 / 빌 1:9 적극적 분별 / 약 1:5 구하라 / W2 운명주의 일관)

**3척도:**

| 척도 | 질문 | 근거 |
|---|---|---|
| **정통** (성경·교리) | 성경 위배? 교리 정통 이탈? | 롬 12:2 마음 갱신·말씀 |
| **사랑** (동기·관계) | 동기가 사랑인가 두려움·탐욕? | 빌 1:9 사랑이 분별 동력 |
| **열매** (방향·결과) | 선한 열매 방향? | 마 7:20 열매로 알리라 |

**5가지 통찰:**
1. 도키마제인 — 분별은 검증 과정 (롬 12:2)
2. 사랑이 분별의 동력 (빌 1:9, W5·W8 일관)
3. 정통 척도 — 성경·교리 위배 X
4. 사랑 척도 — 동기·관계 검증
5. 열매 척도 — 방향·결과 검증

**핵심 통찰:** **분별은 자의적 확신도, 포기도 아니다. 말씀·사랑·열매라는 구체적 척도로 검증하는 과정이다.** 롬 12:2 — 도키마제인, 갱신된 마음에서 검증. 사랑 없는 분별은 차가운 지식 또는 율법주의.
