### L2 — 교리

> *"일상 변화 = 마음 갱신에서 흐름. 의지 강제 X / 벗고 입음 자연스럽게 O. 일상 무관 X / 마음 + 정체성 + 일상 통합 O. 알아차림 + 달려감."*

**거부하는 두 극단:**

❌ **극단 1 — 의지 통제·습관 강제**
- "의지로 끊고 만들면 됨"
- 강박적 자기 통제
- 죄책 정죄로 습관 시도
- "21일 습관 만들기" 절대화
- (왜 거부: W2 자력 변화 일관 / 엡 4:23 마음 갱신 통로 / 강박 = 임상적 위험)

❌ **극단 2 — 습관 무관·일상 환원**
- "일상 습관은 신앙과 무관"
- 영적 자세만 강조 / 일상 회피
- 외형 행동 무시
- (왜 거부: 엡 4:22-24 직접 명시 / 트랙 B W7 일상이 영성의 자리 / 약 1:22 들음 + 행함)

**5가지 통찰:**
1. 벗고 + 입음의 두 동작 (엡 4:22-24)
2. 무거운 짐 벗어버림 (히 12:1 옹코스)
3. 욕심의 잉태 알아차림 (약 1:14-15)
4. 마음 갱신에서 흐름 (의지 강제 X)
5. 일상의 작은 자리에서

**핵심 통찰 1:** **습관 변화는 의지로 만드는 것이 아니라 마음 갱신과 정체성의 자리에서 흘러나오는 것.** W4 마음 → W5 정체성 → W6 일상의 흐름.

**핵심 통찰 2:** **욕심 자체를 정죄 X / 끌려가는 자세를 알아차림** (약 1:14). 욕심은 자연스러운 부분. 끌려가는 자세를 알아차림이 회피의 자리.
