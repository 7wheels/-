### L2 — 교리

> *"변화는 자기 노력의 결과 X / 받음에서 흐르는 수동태. 메타모르푸오메다. 자기 의지의 절대화 X / 운명론 X. 그리스도를 바라봄으로 변화를 받음."*

**예고하는 두 극단 (W2·W3 깊이):**

❌ **극단 1 — 자력 변화·의지력 절대화 (W2)**
- "변화는 자기 의지·결단·노력의 결과"
- 죄책 정죄로 변화 시도
- "더 강한 결심으로 됨"
- 외형 만들기에 집중
- (왜 거부: 메타모르푸오메다 수동태 / 갈 3:3 / 빌 2:13 / 트랙 C W3 일관)

❌ **극단 2 — 변화 무력화·운명론 (W3)**
- "나는 못 바뀜·이 정도가 한계"
- 자기 비관·낮은 자기상
- "성격이라서·세상이 안 변하니"
- 자기 정죄 자리
- (왜 거부: 고후 5:17 카이네 크티시스 / 빌 1:6 / 자기 정죄 = 고소자 음성)

**5가지 통찰:**
1. 메타모르푸오메다 — 수동태 (고후 3:18)
2. 바라봄에서 변화 (카토프트리조메노이)
3. 마음 갱신이 통로 (롬 12:2, W4 깊이)
4. 시작하신 이가 이루심 (빌 1:6)
5. 점진적 변화 — 영광에서 영광

**핵심 통찰 1:** **변화는 부산물이지 목표가 아니다.** "바뀌어야 한다"고 직접 노력하면 자력 변화로 빠짐. "그리스도를 보라" — 그러면 변화가 흘러나옴.

**핵심 통찰 2:** **변화는 시간이 걸린다.** "영광에서 영광" — 일회성 결단 X / 평생의 자리 O.
