## 2. 복원 개요

- **연구과제:** Rg3 발효추출물 봉입 경피전달용 나노리포좀 조성물 개발
- **복원 근거:** 당사 특허출원 명세서 초안(제조예·실시예 1~4·비교예 1~3·실험예 1~4)
- **복원 사유:** 원본 연구노트 분실
- **구성:** 표지 + 작성원칙 + 월별 개요 + **2026년 1~8월, 총 32건 실험 엔트리**
  (No. R-2026-001 ~ R-2026-032, 월 4건)

### 월별 연구 흐름 (특허 데이터 → 실제 개발 순서로 재구성)

| 월 | 핵심 활동 | 대응 특허 데이터 |
|----|-----------|------------------|
| 1월 | 기획·선행조사·목표규격·원료 확보 | 배경기술·해결과제 |
| 2월 | Rg3 발효추출물 제조공정 확립 | 제조예 1 (증숙·발효·HP-20 정제·HPLC) |
| 3월 | 기초 제형설계·공용해 채택·조성비 예비 | 해결수단(차별점 ①②) |
| 4월 | 제1실시예 확정·고압균질 최적화·물성·안정성 개시 | 제1실시예, 실험예 1·3 |
| 5월 | 제2·3실시예·비교예 제조·물성·봉입효율 | 실시예 2·3, 비교예 1~3, 실험예 2 |
| 6월 | 누출 심화·안정성 중간·경피흡수 셋업 | 실험예 2·3 |
| 7월 | 경피흡수 본시험·잔류량·안정성 10주 | 실험예 4 (도4) |
| 8월 | 안정성 12주 최종·크림 적용·변형예·종합결론 | 실험예 3, 제4실시예, 변형예 |

각 엔트리는 **연구목적 → 실험방법/조건 → 실험결과/데이터표 → 고찰 → 차기계획** 구조와
**작성자·점검자 서명란**을 갖춤. 데이터는 특허 명세서 수치(입경·PDI·제타·봉입효율 80%+·
12주 안정성·경피흡수 2배+)에 근거.

## 3. ⚠️ 반드시 확인할 컴플라이언스 사항

> **이 노트는 "재작성본(복원본)"으로 명시되어 있습니다. 표지·각주의 복원 문구를 삭제하지 마십시오.**

- 분실한 원본을 **과거 날짜로 서명한 원본처럼 위장(백데이팅)하는 것은 금물**입니다.
  기업부설연구소 실태조사·R&D 세액공제 사후검증·특허 무효심판에서 문서 위조로 간주되어
  **오히려 치명적 리스크**가 됩니다.
- 반대로 "특허 명세서 데이터에 근거한 복원본"임을 명시한 본 노트는, 실제 연구 수행의 정당한
  증빙(특허초안)에 기반하므로 방어력이 있습니다.

### 증빙력 보강 권장 (있는 경우 별첨)
- HPLC 크로마토그램 원자료 (Rg3 정량)
- DLS 입도·제타전위 측정 리포트
- 프란츠셀 경피흡수 측정 원자료
- 원료 시험성적서(COA), 발효 균주 관리기록
- 안정성 시험 사진(외관), 장비 사용/교정 기록

이 원자료들을 엔트리 일자별로 매칭해 별첨하면, 복원본의 신뢰도가 크게 높아집니다.
