## 핵심 설계 원칙 (요약)

1. **검증된 것만 특허낸다** — 검증 게이트 통과 후 특허 단계 진입
2. **신규성 보호** — 출원 전 핵심 기술 공개 금지
3. **출원번호 = 무기** — 등록까지 안 가도 사업계획서 기술성·가점에 강력
4. **공고 달력 역산** — 종료 시점을 주요 지원사업 모집기에 맞춤
5. **표현 컴플라이언스** — "선정/자금 보장" 금지, "준비/지원"으로 통일
