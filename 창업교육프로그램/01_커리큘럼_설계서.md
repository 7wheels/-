# 올인원 예비창업자 프로그램 — 상세 커리큘럼 설계서

> **한 줄 정의**: 자기성향 진단으로 사업 방향을 찾고 → 아이템을 발굴·검증·구조화하여 → 특허(출원)로 보호하고 → 그 특허를 무기로 정부지원사업·정책자금 사업계획서까지 완성하는 **10주 하이브리드 올인원 프로그램**.

- **대상**: 일반 예비창업자 (분야 무관, 아이템 미확정자도 가능)
- **형태**: 하이브리드 (온라인 라이브 강의 + 오프라인 핵심 워크샵)
- **기간**: 10주 (기수제, 1기 정원 12~20명 권장)
- **수료 기준**: 출석이 아니라 **단계별 산출물 완성**으로 정의 (아래 산출물 맵 참조)

---

## 0. 설계 철학 — 왜 이 순서인가

### 핵심 원칙: "검증된 것만 특허낸다"

가장 흔한 실패는 **검증 없이 특허부터 내는 것**입니다. 등록 가능한(patentable) 아이템과 팔리는(sellable) 아이템은 다릅니다. 그래서 본 프로그램의 순서는:

```
성향진단 → 아이템발굴 → 빠른검증 → 구조화 → (검증된 것만) 특허전략·출원 → 사업계획서 → 지원실행
```

### 두 가지 타이밍 규칙 (반드시 지켜야 함)

1. **신규성(novelty) 보호**: 특허 출원 *전에는* 아이디어의 핵심 기술 내용을 공개 발표·크라우드펀딩·온라인 게시하지 않는다. (한국에 공지예외 12개월 제도가 있으나 의존하지 않는다)
2. **공고 달력 역산**: 프로그램 종료 시점이 주요 정부지원 공고 모집기와 맞물리도록 기수 일정을 역산한다. (예: 예비창업패키지 시즌 직전 종료)

### 표현 컴플라이언스

- "자금/선정 **보장**" ❌ → "선정 가능성을 극대화하는 준비" ⭕
- 환불·과장광고 분쟁을 막기 위해 모든 홍보·계약 문구는 "보장"이 아닌 "준비/지원"으로 통일한다.

## 1. 전체 구조 한눈에 보기

| 주차 | 모듈 | 형태 | 핵심 산출물 |
|---|---|---|---|
| 1주 | M0. 온보딩 + 창업 마인드셋 세팅 | 오프라인 (킥오프) | 창업 준비도 자가진단표 |
| 2주 | M1. 프레디저 진단 → 사업 방향 찾기 | 온라인 | 성향·사업방향 리포트 |
| 3주 | M2. 아이템 발굴·선정 | 온라인 | 아이템 후보 3개 + 1-pager |
| 4주 | M3. 시장 검증 ① (고객·문제 검증) | 오프라인 워크샵 | 고객 인터뷰 보고서 |
| 5주 | M3. 시장 검증 ② (MVP·수요 검증) | 온라인 | MVP 검증 보고서 |
| 6주 | M4. 아이템 구조화 (BM·페르소나·수익모델) | 오프라인 워크샵 | 비즈니스 모델 캔버스 |
| 7주 | M5. 특허 전략 ① (선행조사·특허성 판단) | 온라인 (+변리사) | 선행기술 조사 보고서 |
| 8주 | M5. 특허 전략 ② (명세서 초안·출원) | 온라인 (+변리사) | 특허 명세서 초안 / 출원 |
| 9주 | M6. 사업계획서 작성 (정부지원·정책자금) | 오프라인 워크샵 | 사업계획서 초안 |
| 10주 | M7. 피칭 + 지원 실행 (데모데이) | 오프라인 (데모데이) | 완성 사업계획서 + IR 피치덱 + 지원 제출 |

> **하이브리드 배치 원칙**: 협업·피드백·신뢰가 중요한 단계(킥오프, 검증, 구조화, 사업계획, 데모데이)는 **오프라인**, 지식 전달·전문가 세션은 **온라인 라이브**로 배치.

## 2. 모듈별 상세 설계

### M0. 온보딩 + 창업 마인드셋 세팅 (1주 / 오프라인 킥오프)

**목표**: 동기 정렬, 관계 형성, 현실적 기대치 세팅, 마인드셋 기반 다지기.

- **학습 내용**
  - 프로그램 전체 여정 지도 그리기 (10주 후 내 손에 남는 것)
  - 창업가 마인드셋: 의사결정 프레임, 실패를 데이터로 보기, 번아웃·공동창업자 갈등 관리
  - "왜 나는 창업하려는가" — Why 정의 워크샵
- **활동**: 1:1 목표 인터뷰, 동기별 팀 빌딩, 서약식(완주 약속)
- **산출물**: 창업 준비도 자가진단표 (재무 여력, 시간, 리스크 감내, 네트워크)
- **강사/자원**: 메인 퍼실리테이터
- **체크포인트**: 비현실적 기대(예: 자금 보장 기대)를 가진 수강생을 조기에 정렬

---

### M1. 프레디저(Prediger) 진단 → 사업 방향 찾기 (2주 / 온라인)

**목표**: 성향을 사업 방향·역할로 번역한다. (단순 성향 파악으로 끝내지 않음)

- **핵심 개념**: 프레디저 모델의 **데이터 / 아이디어 / 사람 / 사물** 4축 흥미를 진단하고, 이를 사업 유형·창업가 역할로 연결.
  - 데이터 지향 → 분석·핀테크·데이터 비즈니스
  - 아이디어 지향 → 콘텐츠·기획·디자인·R&D
  - 사람 지향 → 교육·서비스·영업·커뮤니티
  - 사물 지향 → 제조·하드웨어·물류·요식
- **활동**: 진단 → 결과 해석 → "내 성향 × 시장 기회" 매트릭스 작성 → 적합한 **창업가 역할**(기획형/영업형/기술형) 도출
- **산출물**: 성향·사업방향 리포트 (강점/약점/보완 필요 역량 + 적합 사업 유형 Top 3)
- **연결**: 이 리포트가 M2 아이템 발굴의 **입력값**이 됨. 또 부족 역량은 "어떤 공동창업자가 필요한가"로 연결.

---

### M2. 아이템 발굴·선정 (3주 / 온라인)

**목표**: 막연한 아이디어를 검증 가능한 아이템 후보로 좁힌다.

- **학습 내용**
  - 아이템 발굴 3경로: ① 내 경험·불편(Pain) ② 시장 트렌드·정책 방향 ③ 기존 시장의 비효율
  - 아이템 평가 기준: 시장성 / 실현가능성 / 차별성 / **특허 가능성** / 나의 적합도
- **활동**: 아이템 후보 5개 브레인스토밍 → 평가 매트릭스로 3개로 압축 → 각 후보 1-pager 작성
- **산출물**: 아이템 후보 3개 + 선정된 1개의 1-pager (문제/해결/타깃/차별점)
- **도구 연계**: 네이버 데이터랩(검색 트렌드·쇼핑 트렌드), 키워드 검색량으로 수요 신호 1차 확인
- **주의**: 이 단계까지는 아이디어 **상세 공개 금지** (특허 신규성 보호)

---

### M3. 시장 검증 (4~5주)

#### M3-① 고객·문제 검증 (4주 / 오프라인 워크샵)

**목표**: "이게 진짜 고객의 문제인가"를 사람으로 확인한다.

- **학습 내용**: 고객 인터뷰 설계(유도질문 금지), 문제 가설 검증, JTBD(Jobs To Be Done)
- **활동**: 인터뷰 질문지 작성 → (1주간) 실제 잠재고객 5~10명 인터뷰 → 워크샵에서 인사이트 공유
- **산출물**: 고객 인터뷰 보고서 (검증된 문제 / 기각된 가정 / 새 발견)

#### M3-② MVP·수요 검증 (5주 / 온라인)

**목표**: "돈/행동으로 증명되는 수요"를 본다.

- **학습 내용**: 노코드 MVP, 랜딩페이지 + 사전신청, 스모크 테스트, 검증 지표 설정
- **활동**: 최소 검증 자산(랜딩/설문/시제품 컨셉) 제작 → 수요 신호 수집
- **산출물**: MVP 검증 보고서 (전환율·관심도·핵심 지표 + Go/Pivot/Stop 결론)
- **핵심 게이트**: 여기서 **검증 통과한 아이템만** M5 특허 단계로 진입 (검증 실패 시 Pivot 후 재검증)

---

### M4. 아이템 구조화 (6주 / 오프라인 워크샵)

**목표**: 검증된 아이템을 사업으로 구조화한다.

- **학습 내용**: 비즈니스 모델 캔버스, 페르소나, 수익모델, 가격전략, 경쟁구도(포지셔닝 맵)
- **활동**: BMC 9칸 작성 → 핵심 페르소나 정의 → 수익 구조·단가 설계 → 동료 피드백
- **산출물**: 비즈니스 모델 캔버스 + 페르소나 + 수익모델 1장 요약
- **연결**: 이 구조가 M6 사업계획서의 뼈대가 됨

---

### M5. 특허 전략 (7~8주 / 온라인 + 변리사 협업)

> ⚠️ **외부 전문가 필수**: 강사가 변리 업무를 대행할 수 없습니다. 제휴 변리사 사무소를 모듈 설계 단계에서 확보하세요.

#### M5-① 선행조사·특허성 판단 (7주)

- **학습 내용**: 특허/실용신안/디자인/상표 차이, 신규성·진보성 개념, 특허 vs 영업비밀 판단
- **활동**: KIPRIS 선행기술 조사, 특허 가능성 자가진단, 변리사 1차 상담
- **산출물**: 선행기술 조사 보고서 + 출원 전략 결정서(출원/영업비밀/디자인 등)
- **비용 현실 안내**: 출원 비용·관납료·변리사 수임료 구조, 정부 IP 지원사업(IP나래·공익변리사) 안내

#### M5-② 명세서 초안·출원 (8주)

- **학습 내용**: 청구항의 개념, 명세서 구조, "넓고 강한 권리"를 위한 작성 원리
- **활동**: 발명 신고서 작성 → 변리사와 명세서 초안 정리 → (가능 시) 출원 진행
- **산출물**: 특허 명세서 초안 / **출원번호**
- **전략 포인트**: 등록까지 안 가도 됨. **출원번호만으로도** 정부지원사업 기술성·가점에 충분히 강력. 이후 발표·IR에서 안전하게 공개 가능해짐.

---

### M6. 사업계획서 작성 — 정부지원·정책자금 (9주 / 오프라인 워크샵)

**목표**: 특허·검증 데이터를 근거로 심사에 통하는 사업계획서를 쓴다.

- **학습 내용**
  - 정부지원 사업계획서 표준 프레임 **PSST** (Problem–Solution–Scale-up–Team)
  - 정책자금 vs 정부지원사업(R&D/사업화) 차이, 융자 vs 출연
  - 심사위원 관점: 무엇을 보고 점수를 주는가
- **활동**: PSST 프레임에 자기 데이터 채워넣기 → 동료·멘토 교차 첨삭
- **산출물**: 사업계획서 초안
- **연결**: 앞 모듈 산출물(검증 보고서·BMC·출원번호)을 근거 자료로 그대로 인용

---

### M7. 피칭 + 지원 실행 — 데모데이 (10주 / 오프라인)

**목표**: 완성하고, 실제로 제출하고, 말로 설득한다.

- **학습 내용**: IR 피치덱 구성, 5분 피칭 스크립트, 예상 질의응답
- **활동**: 피치덱 제작 → 리허설 → **데모데이(외부 멘토·심사위원 초청)** → 실제 공고 지원 제출
- **산출물**: 완성 사업계획서 + IR 피치덱 + **지원 제출 완료**
- **사후 연계(권장)**: 수료생 대상 후속 액셀러레이팅·멘토링·동문 네트워크, 선정 후 자금 집행·세무 연계

---

## 3. 수료 산출물 맵 (포트폴리오)

수료 시 수강생 손에 남는 결과물 — 이것이 곧 최고의 모객 무기입니다.

1. 창업 준비도 자가진단표
2. 성향·사업방향 리포트
3. 아이템 1-pager
4. 고객 인터뷰 보고서
5. MVP 검증 보고서
6. 비즈니스 모델 캔버스
7. 선행기술 조사 보고서 + 출원 전략 결정서
8. 특허 명세서 초안 / 출원번호
9. 정부지원 사업계획서 (완성본)
10. IR 피치덱

## 4. 운영 체크리스트

### 시작 전 (D-8주 ~ D-4주)
- [ ] **공고 달력 역산**: 종료일을 목표 공고 모집기에 맞춰 기수 일정 확정
- [ ] **변리사 제휴** 확보 (M5 협업)
- [ ] 회계사·세무사·정책자금 멘토 풀 확보 (사후 연계)
- [ ] 오프라인 공간·온라인 라이브 플랫폼 확정
- [ ] 프레디저 진단 도구 라이선스/대체 진단 확정
- [ ] 산출물 템플릿 세트 준비 (별도 문서)
- [ ] 환불·계약·표현 컴플라이언스 점검 ("보장" 표현 제거)

### 운영 중
- [ ] 매 모듈 종료 시 산출물 제출·피드백 (진도 = 산출물)
- [ ] M3-② 검증 게이트 운영 (통과한 아이템만 특허 진입)
- [ ] 특허 출원 전 아이디어 공개 금지 안내 반복

### 종료 후
