# 3주차
## 검증 게이트 + 비즈니스 모델 구조화
오프라인 워크샵 · 4시간

---

## 오늘 끝나면

- 검증 데이터를 **보고서**로 정리한다
- **Go / Pivot / Stop** 을 판단한다 (게이트)
- 통과 아이템을 **사업으로 구조화**한다

**산출물**: ④ 인터뷰 보고서 · ⑤ 수요 검증 보고서 · ⑥ BMC

---

## 실습 1 — 검증 보고서 정리

**고객 인터뷰 보고서** (워크북 ④)
- 검증된 문제 / 기각된 가정 / 새 발견

**수요 검증 보고서** (워크북 ⑤)
- 전환율·관심도 지표 → 결론 한 줄

---

## 🚪 검증 게이트

> 지금부터 냉정해집시다.

- 1인 3분 발표 → **Go / Pivot / Stop** 판정
- **Pivot은 실패가 아니다** — 데이터 기반 방향 수정
- 검증 안 된 아이템에 특허비·시간 쓰는 것을 막는 단계

> Go 판정 아이템만 다음 주(특허)로 진입

---

|---|---|---|---|---|
|  | 자원 |  | 채널 |  |

| 비용 구조 | **수익원** |
|---|---|

> 핵심: '가치 제안 ↔ 수익원'이 **검증 데이터로** 연결되는가

---

## 실습 2 — 구조화

워크북 ⑥ (벽면 포스트잇)

- BMC 9칸 작성
- **페르소나** 1인 정의 (Pain → Gain)
- 수익모델: 단가 · 원가 · 마진 · 손익분기

⏱ 워크샵 + 갤러리워크(서로 피드백)
