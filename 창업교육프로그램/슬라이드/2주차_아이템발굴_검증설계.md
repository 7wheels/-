# 2주차
## 아이템 발굴·선정 + 검증 설계
온라인 라이브 · 3시간

---

## 오늘 끝나면

- 후보 5개를 **1개**로 좁힌다
- 아이템 **1-pager**를 완성한다
- 주중에 돌릴 **검증 계획**을 손에 쥔다

**산출물**: ③ 아이템 1-pager · 검증 계획

---

## 아이템 평가 5축

| 축 | 질문 |
|---|---|
| 시장성 | 충분히 큰/성장하는 시장인가 |
| 실현가능성 | 내 자원으로 만들 수 있나 |
| 차별성 | 기존 대안과 무엇이 다른가 |
| **특허가능성** | 보호할 기술 요소가 있나 |
| 나의 적합도 | 내 성향·역량과 맞나 |

---

## 시연 — 수요 신호 1차 확인

- 네이버 데이터랩: 검색 트렌드 · 쇼핑 트렌드
- 키워드 검색량으로 "사람들이 찾고 있는가" 확인
- 주의: 검색량은 **참고 신호**일 뿐, 진짜 검증은 다음 단계

---

## 실습 — 후보 → 1개 선정

평가 매트릭스 채점 (워크북 ③)

| 후보 | 시장성 | 실현 | 차별 | 특허 | 적합 | 합계 |
|---|---|---|---|---|---|---|
| A | | | | | | |
| B | | | | | | |
| C | | | | | | |

→ 최고 점수 1개 + **선정 이유** → 1-pager 작성

---

## 검증 = 이번 주의 핵심

> 다음 주, **검증 게이트**를 통과한 아이템만 특허로 갑니다.

- 검증 없이 특허내는 것이 **가장 흔한 돈 낭비**
- 검증은 두 가지: ① 고객·문제 ② 수요(행동)

---

## 좋은 인터뷰 질문

- ❌ "이거 나오면 사실래요?" → 사람들은 거짓말한다
- ⭕ "최근에 이 문제로 **돈·시간을 쓴 적** 있나요?"
- 과거의 **행동**을 묻는다 (의견·미래가 아니라)
- JTBD: 고객이 '고용'하려는 진짜 일은 무엇인가

---

## 실습 — 검증 설계

워크북에 작성

- 만나야 할 고객 정의 (지인 위주 ❌)
- 인터뷰 질문 5개 (유도질문 금지)
- 수요 검증 방법: 랜딩+사전신청 / 설문 / 스모크테스트

---

## 주중 과제 ★

- [ ] 잠재고객 **5~10명 인터뷰** + 기록
- [ ] 수요 신호 수집 (전환·관심·결제의향)

> 5주 중 가장 중요한 한 주. 발로 뛴 데이터가 다음 모든 단계의 근거가 됩니다.
