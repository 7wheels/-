# 운영교안 (5주 / 강사 진행용)

> 실제 세션을 그대로 진행할 수 있는 **런시트(run-sheet)** 입니다.
> 각 주차마다: 개요 → 준비물 → 분 단위 타임테이블 → 강사 진행 스크립트 → 실습 지시문 → 주중 과제 → 산출물·체크포인트 순으로 구성.
> 시간은 권장값이며 정원·공간에 맞게 ±조정하세요. (정원 12~16명 기준)

## 5주 전체 흐름 (압축 구조)

핵심 원리: **세션은 "전환·피드백·구조화"에 쓰고, 검증·인터뷰·조사는 주중 과제로 돌린다.**

| 주차 | 형태 | 세션 시간 | 주제 | 핵심 산출물 | 주중 과제 |
|---|---|---|---|---|---|
| 1주 | 오프라인 킥오프 | 4h | 마인드셋 + 프레디저 진단 → 사업방향 | 자가진단표 / 성향·방향 리포트 | 아이템 후보 발굴 |
| 2주 | 온라인 라이브 | 3h | 아이템 발굴·선정 + 검증 설계 | 아이템 1-pager / 검증 계획 | **고객 인터뷰 5~10명 + 수요 신호** |
| 3주 | 오프라인 워크샵 | 4h | 검증 결과 정리(게이트) + 구조화 | 인터뷰·MVP 검증 보고서 / BMC | KIPRIS 선행조사 |
| 4주 | 온라인 + 변리사 | 3h | 특허 전략·출원 준비 | 선행조사 보고서 / 발명 신고서 → 출원 | 사업계획서 1차 초안 |
| 5주 | 오프라인 데모데이 | 4h | 사업계획서(PSST) 완성 + 피칭 | 사업계획서 / IR 피치덱 / **지원 제출** | (사후) 지원 실행 |

> 10개 산출물(설계서 참조)은 5주 안에 모두 생성됩니다. 특허는 기간상 **출원 준비·변리사 연계**까지 완료, 출원번호는 프로그램 직후 확보되는 경우가 많습니다.

# 1주차 — 마인드셋 + 프레디저 진단 → 사업방향 (오프라인, 4시간)

### 개요
- **목표**: ① 관계·동기 정렬과 현실적 기대치 세팅 ② 프레디저 성향을 "사업 방향·역할"로 번역
- **결과물**: 창업 준비도 자가진단표, 성향·사업방향 리포트
- **형태**: 오프라인 킥오프 (테이블 4인 1조 배치)

### 준비물
- 강사: 명찰, 4인 테이블, 포스트잇·네임펜, 화이트보드, 프레디저(또는 대체) 진단 링크/QR, 워크북(템플릿 1·2 인쇄), 타이머
- 수강생: 노트북/휴대폰, 자신이 막연히 생각한 아이템(있으면)

### 타임테이블
| 시간 | 블록 | 활동 |
|---|---|---|
| 0:00–0:20 | 오프닝 | 환영·프로그램 5주 여정 지도, 그라운드룰 |
| 0:20–0:45 | 아이스브레이킹 | 2인 1조 "왜 창업하려 하는가" 인터뷰 → 서로 소개 |
| 0:45–1:15 | 마인드셋 강의 | 창업가 의사결정·실패=데이터·번아웃/공동창업자 갈등 |
| 1:15–1:35 | 실습 | 창업 준비도 자가진단표 작성 (템플릿 1) |
| 1:35–1:45 | 휴식 | |
| 1:45–2:30 | 프레디저 진단 | 진단 실시 + 4축(데이터/아이디어/사람/사물) 해석 강의 |
| 2:30–3:15 | 실습 | 성향 → 적합 사업유형 Top3 + 창업가 역할 도출 (템플릿 2) |
| 3:15–3:45 | 조별 공유 | 각자 성향·방향 1분 발표, 조원 피드백 |
| 3:45–4:00 | 마무리·과제 | 다음 주 과제 안내, 완주 서약 |

### 강사 진행 스크립트 (멘트 예시)
- **오프닝**: "이 5주가 끝나면 여러분 손에는 막연한 생각이 아니라, 제출할 수 있는 사업계획서와 검증 데이터가 남습니다. 단, 한 가지 규칙이 있어요. **출석이 아니라 결과물이 진도**입니다."
- **기대치 세팅**: "분명히 말씀드립니다. 우리는 정부지원 '선정'을 보장하지 않습니다. 대신 선정 가능성을 최대로 끌어올리는 준비를 함께 끝까지 합니다."
- **프레디저 해석**: "성향 진단은 '나를 알자'로 끝내면 절반만 쓴 겁니다. 핵심은 '내 성향에 맞는 사업 유형은 무엇이고, 내가 못하는 영역은 누구와 함께할 것인가'까지 가는 겁니다."

### 실습 지시문
1. (자가진단) 6개 항목 1~5점 + Why 3문장. → 조원과 "가장 두려운 것" 1개 공유.
2. (성향번역) 4축 점수 → 적합 사업유형 Top3 → 나의 역할(기획/영업/기술) → 보완역량 → 필요한 파트너 유형.

### 주중 과제
- 성향·방향에 맞춰 **아이템 후보 5개** 브레인스토밍해 오기 (경험·불편 / 트렌드 / 시장 비효율 3경로 활용)
- ⚠️ 안내: 지금부터 아이템 핵심 아이디어는 외부 공개 금지 (특허 신규성 보호)

### 체크포인트
- [ ] 전원 자가진단표·성향 리포트 제출
- [ ] 비현실적 기대(자금 보장 등) 보유자 1:1 정렬
- [ ] 완주 서약 완료

### 개요
- **목표**: 후보 아이템을 1개로 좁히고, 주중에 돌릴 **검증 계획**을 완성
- **결과물**: 아이템 1-pager, 검증 계획(인터뷰 질문지 + 수요 검증 방법)
- **형태**: 온라인 라이브 (소회의실 기능 활용)

### 준비물

# 3주차 — 검증 결과 정리(게이트) + 아이템 구조화 (오프라인, 4시간)

### 개요
- **목표**: 검증 데이터로 Go/Pivot/Stop 판단 → 통과 아이템을 사업으로 구조화
- **결과물**: 고객 인터뷰 보고서, MVP/수요 검증 보고서, 비즈니스 모델 캔버스
- **형태**: 오프라인 워크샵 (벽면 BMC 대형 출력 활용)

### 준비물
- 강사: BMC 대형 출력(A1)·포스트잇, 검증 게이트 판정 보드, 페르소나 시트, 멘토(가능 시 초청)
- 수강생: 인터뷰·수요 검증 결과 데이터

### 타임테이블
| 시간 | 블록 | 활동 |
|---|---|---|
| 0:00–0:15 | 체크인 | 과제 수행 현황 빠른 공유 |

| 1:20–1:30 | 휴식 | |
| 1:30–2:30 | 워크샵 | 비즈니스 모델 캔버스 9칸 작성 (벽면, 포스트잇) |

- **게이트**: "지금부터 냉정해집시다. 검증이 안 된 아이템에 특허비·시간을 쓰는 건 막아드리는 게 제 역할입니다. Pivot은 실패가 아니라 데이터 기반 방향수정입니다."
- **구조화**: "BMC는 9칸을 다 채우는 게 목적이 아닙니다. '가치 제안'과 '수익원'이 검증 데이터로 연결되는지가 핵심입니다."

### 실습 지시문
1. 인터뷰 보고서: 검증된 문제 / 기각된 가정 / 새 발견.
2. 수요 검증 보고서: 지표·전환율 + Go/Pivot/Stop 결론 한 줄.
3. BMC 9칸 + 페르소나 1인 + 단가/마진/손익분기 메모.

### 주중 과제
- KIPRIS에서 **선행기술 3건 이상** 조사해 유사점·차이점 정리 (템플릿 7 일부)

### 체크포인트
- [ ] 전원 게이트 판정 완료 (Go가 아니면 Pivot 방향 확정)
- [ ] BMC '가치제안↔수익원' 연결성 점검

# 4주차 — 특허 전략·출원 준비 (온라인 + 변리사, 3시간)

### 개요
- **목표**: 특허성 판단 → 출원 전략 결정 → 발명 신고서 작성 → 변리사 연계
- **결과물**: 선행기술 조사 보고서, 출원 전략 결정서, 발명 신고서(→ 명세서 초안/출원)
- **형태**: 온라인 라이브 + **제휴 변리사 게스트 세션**

> ⚠️ 변리사 섭외 필수. 강사는 변리 업무를 대행할 수 없습니다.

### 준비물
- 강사: 특허/실용신안/디자인/상표 비교 슬라이드, 발명 신고서 양식, 변리사 1:1 상담 슬롯표
- 변리사: 신규성·진보성·청구항 개념, IP 지원사업(IP나래·공익변리사) 안내
- 수강생: 선행조사 결과

### 타임테이블
| 시간 | 블록 | 활동 |
|---|---|---|
| 0:00–0:10 | 체크인 | 선행조사 과제 공유 |
| 0:10–0:45 | 강의(변리사) | 특허 vs 실용신안/디자인/상표/영업비밀, 신규성·진보성 |
| 0:45–1:15 | 강의(변리사) | 청구항·명세서 기본, "넓고 강한 권리" 원리, 비용 구조·IP 지원사업 |
| 1:15–1:25 | 휴식 | |
| 1:25–1:55 | 실습 | 출원 전략 결정서 작성(특허/실용신안/디자인/비밀) (템플릿 7) |
| 1:55–2:35 | 실습 | 발명 신고서 작성 (템플릿 8) |
| 2:35–3:00 | Q&A | 변리사 단체 Q&A + 1:1 상담 예약 |

### 강사 진행 스크립트
- **출원번호의 가치**: "특허 '등록'까지 5주 안엔 못 갑니다. 괜찮습니다. **출원번호만 있어도** 사업계획서 기술성·가점에 충분히 강력합니다. 출원 후부터는 다음 주 피칭에서 안전하게 공개할 수 있어요."
- **비용 현실**: "관납료·수임료가 부담되면 IP나래·공익변리사 같은 지원제도가 있습니다. 무조건 특허가 답도 아니에요 — 영업비밀이 나은 경우도 있습니다."

### 실습 지시문
1. 선행조사 표 완성 → 나의 신규성·진보성 포인트 1줄.
2. 보호 방식 결정 + 이유 + 활용할 IP 지원사업.
3. 발명 신고서: 명칭/과제/해결수단/구성요소/효과/도면 스케치 → 변리사 전달용.

### 주중 과제
- 발명 신고서 변리사 전달(출원 진행자) + **사업계획서 1차 초안**(PSST 골격) 작성

### 체크포인트
- [ ] 전원 출원 전략 결정서 + 발명 신고서 제출
- [ ] 출원 진행 의사자 변리사 1:1 예약 완료

# 5주차 — 사업계획서(PSST) 완성 + 피칭 데모데이 (오프라인, 4시간)

### 개요
- **목표**: 검증·특허 데이터를 근거로 사업계획서를 완성하고, 피칭하고, **실제 공고에 제출**
- **결과물**: 정부지원 사업계획서 완성본, IR 피치덱, 지원 제출
- **형태**: 오프라인 + 외부 멘토·심사위원 초청 데모데이

### 준비물
- 강사: PSST 템플릿, 피치덱 10슬라이드 양식, 타이머·발표 화면, 외부 멘토 섭외, (가능 시) 목표 공고 링크·제출 가이드
- 수강생: 사업계획서 1차 초안, 노트북

### 강사 진행 스크립트
- **심사관점**: "심사위원은 30초 안에 '문제–해결–차별–근거'를 찾습니다. 첫 페이지에 다 보이게 하세요. 차별성에는 반드시 **출원번호**를 박으세요."
- **제출 클로징**: "오늘 끝이 아닙니다. 오늘 '제출 버튼'까지 누르고 갑시다. 생각만 하고 끝낸 작년과 다른 점이 그거예요."

### 실습 지시문
1. PSST 4파트 완성 — 각 주장에 근거(인터뷰/지표/출원번호/BMC) 인용.
2. 피치덱 10슬라이드 + 후킹 한 문장 + 예상 질문 3개·답변.
3. 목표 공고 1개 선정 → 제출(또는 제출 체크리스트 완료).

### 체크포인트
- [ ] 전원 사업계획서 완성본 + 피치덱 제출
- [ ] 제출(또는 제출 준비 완료) 인원 집계 — 다음 기수 모객 근거
- [ ] 사후 연계 안내(변리사 출원 마무리, 세무·자금, 동문 네트워크)

## 부록 A. 강사 공통 운영 원칙
- **진도 = 산출물**: 매주 산출물 제출로 진도 인정. 미제출자 1:1 보충.
- **검증 게이트(3주)**: 통과 아이템만 특허(4주) 진입. Pivot 적극 허용.
- **신규성 보호**: 출원(4주) 전까지 핵심 기술 외부 공개 금지 반복 안내.
- **표현 컴플라이언스**: 모든 멘트·자료에서 "선정/자금 보장" 금지 → "준비/지원".
- **공고 달력 역산**: 5주차 종료를 목표 공고 모집기 직전에 배치.
