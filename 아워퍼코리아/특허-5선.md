## 주제 No. 1 — 최우선 추천

- **발명의 명칭(가안):** 저온 진공 발효 추출물을 함유한 피부 장벽 개선용 화장료 조성물
  (Cosmetic Composition for Improving Skin Barrier Containing Low-Temperature Vacuum Fermented Extract)
- **영역:** A. 조성물(처방) 특허
- **핵심 발명 요지:**
  통상의 발효 추출은 30~37℃ 상온 조건에서 수행되어 열에 약한 유효성분(폴리페놀·비타민 C 유도체 등)이 파괴되는 한계가 있다. 본 발명은 **15~20℃ 저온 + 진공 감압 조건**에서 락토바실러스 또는 사카로마이세스 균주로 식물 추출물(예: 병풀·어성초·녹차)을 발효시켜, 활성성분 보존율을 기존 대비 1.5배 이상 향상시킨다. 발효 산물에 히알루론산·세라마이드 NP를 일정 중량비로 결합한 조성물을 청구한다.
- **권리 범위(청구항 가안):**
  "전체 조성물 100중량부에 대하여, 15~20℃ 및 100~500mbar 조건에서 락토바실러스 플란타룸으로 발효시킨 병풀 추출물 1~10중량부, 세라마이드 NP 0.1~3중량부, 히알루론산 0.05~2중량부를 포함하는 피부 장벽 개선용 화장료 조성물."
- **신규성·진보성 포인트:**
  - 저온 + 진공 조건 결합은 발효 화장품 분야에서 흔치 않음
  - 발효 균주 + 식물원료 + 보습 활성성분 3중 결합으로 청구항 차별화
  - 보존율·피부 흡수율 등 정량 데이터로 진보성 입증 가능
- **벤처인증 적합도:** **4.7/5**
- **실현가능성:** **중** — 발효조·진공장비·HPLC 분석은 외주(CRO·대학산학협력단) 활용 가능. 자체 보유 시 더 강력.
- **예상 출원 비용·기간:**
  - 변리사 수임료 250~350만원 + 관납료 약 70만원 = **약 350만원**
  - 출원 → 우선심사 신청 시 등록까지 **약 8~12개월**, 일반심사 **15~20개월**
- **벤처인증과의 시너지:**
  벤처인증 기술성 평가에서 "차별화된 원천기술 보유"로 인정받기 가장 좋은 유형. 발효 키워드는 K-뷰티 트렌드와도 부합하여 사업성 평가까지 동반 상승 효과.
- **주의·리스크:**
  - 발효 화장품 선행특허(아모레·LG생건·코스맥스) 다수 → 균주 + 온도조건 + 압력조건 + 부원료 4중 한정으로 차별화 필수
  - 발효 데이터(보존율·항산화 활성) 실험 결과를 명세서에 첨부해야 등록 안정성 확보

## 주제 No. 2

- **발명의 명칭(가안):** 이중 챔버 구조를 갖는 활성성분 분리 보관형 화장품 용기
  (Cosmetic Container Having Dual Chamber Structure for Separated Storage of Active Ingredients)
- **영역:** C. 용기·패키징 구조 특허
- **핵심 발명 요지:**
  비타민 C·레티놀·펩타이드 등 산화에 취약한 활성성분을 베이스 처방과 분리 보관하다가, 사용 직전 토출 시점에 1차 혼합되도록 하는 **이중 챔버 + 분리막 파열 구조** 또는 **트위스트 토출 구조**를 갖는 용기. 사용자가 캡을 돌리거나 누르면 분리막이 파열되어 두 액이 자동 혼합되는 방식.
- **권리 범위(청구항 가안):**
  "제1 활성성분이 수용된 상부 챔버, 제2 베이스 조성물이 수용된 하부 챔버, 상기 두 챔버 사이를 분리하는 파열 가능한 분리막, 및 사용자의 회전 조작에 의해 상기 분리막을 천공하는 천공핀을 포함하는 화장품 용기."
- **신규성·진보성 포인트:**
  - 이중 챔버 자체는 공지기술이나, **천공 메커니즘 + 회전 잠금 + 누액 방지 패킹** 결합 구조로 차별화
  - 활성성분의 산화 방지 효과를 정량적으로 입증 시 진보성 견고
- **벤처인증 적합도:** **4.5/5**
- **실현가능성:** **상** — 용기 구조 특허는 자체 R&D 장비 없이 **도면 + 실시예 설명**으로 출원 가능. 금형 제작 전이라도 출원 가능.
- **예상 출원 비용·기간:**
  - 변리사 수임료 + 도면 작성 200~300만원 + 관납료 = **약 300만원**
  - 등록까지 **12~18개월** (구조 특허는 비교적 빠름)
- **벤처인증과의 시너지:**
  "제조 + 패키징 통합 역량"을 보여주는 강력한 근거. 디자인 특허보다 발명특허(구조)가 가산점 높음.
- **주의·리스크:**
  - 이중 챔버 용기는 세계적으로 출원이 많은 분야 → 천공 메커니즘 세부 구성을 한정해야 거절 회피
  - 외주 용기 제조사와 공동출원 가능성 검토 필요(권리귀속 사전 정리)

## 주제 No. 3

- **발명의 명칭(가안):** 저전단 박막 유화 공정을 이용한 고함량 세라마이드 에멀젼 제조방법
  (Method for Manufacturing High-Content Ceramide Emulsion Using Low-Shear Thin-Film Emulsification Process)
- **영역:** B. 제조공정 특허
- **핵심 발명 요지:**
  세라마이드는 결정화 경향이 강해 통상 0.1~0.5% 함량이 한계인데, 본 발명은 **저전단(500~1500rpm) + 박막 가열(60~70℃) + 단계적 냉각(2℃/min)** 공정으로 세라마이드를 1~3% 고함량 안정 분산시킨다. 입자 크기 200nm 이하 균일 에멀젼을 형성한다.
- **권리 범위(청구항 가안):**
  "(a) 유상부를 65~70℃에서 가열 용해하는 단계, (b) 수상부를 동일 온도로 가열하는 단계, (c) 500~1500rpm 저전단 조건에서 30~60분간 박막 형태로 유화하는 단계, (d) 분당 2℃의 속도로 30℃까지 단계적 냉각하는 단계를 포함하는, 세라마이드 1~3중량부를 함유하는 화장료 에멀젼의 제조방법."
- **신규성·진보성 포인트:**
  - 통상의 호모믹서 고전단(3000rpm 이상) 방식과 차별
  - 함량·온도·rpm·냉각속도 4가지 파라미터로 청구항 한정
- **벤처인증 적합도:** **4.3/5**
- **실현가능성:** **중** — 자체 유화기 보유 시 즉시 가능. 외주 시 데이터 확보 일정 협의 필요.
- **예상 출원 비용·기간:**
  - **약 350~400만원**, 등록까지 **15~20개월**
- **벤처인증과의 시너지:**
  공정특허는 "제조사로서의 독자 기술력"을 직접 입증. 조성물 특허와 페어링 시 시너지 극대화.
- **주의·리스크:**
  - 공정 파라미터를 너무 좁게 한정하면 회피설계 쉬움 → 변리사와 청구항 폭 협의 필수
  - 입자크기·안정성(45℃ 4주) 데이터를 실시예로 제시해야 등록률 상승

## 주제 No. 4

- **발명의 명칭(가안):** 피부 측정 데이터 기반 개인 맞춤형 화장료 조성 추천 시스템 및 방법
  (Personalized Cosmetic Formulation Recommendation System and Method Based on Skin Measurement Data)
- **영역:** E. 디지털 결합 특허
- **핵심 발명 요지:**
  사용자가 모바일 앱으로 촬영한 피부 이미지(또는 휴대용 측정기 데이터)를 분석하여 **유분·수분·홍반·색소·주름 5개 지표**를 산출하고, 사전 구축된 원료 데이터베이스와 매칭해 개인 맞춤 처방을 자동 생성·추천하는 시스템.
- **권리 범위(청구항 가안):**
  "사용자 단말로부터 피부 이미지를 수신하는 통신부, 상기 이미지로부터 유분·수분·홍반·색소·주름 지표를 산출하는 분석부, 원료별 효능·함량 정보를 저장하는 데이터베이스, 상기 산출된 지표와 데이터베이스를 매칭하여 추천 처방을 생성하는 추천부를 포함하는 맞춤형 화장료 추천 시스템."
- **신규성·진보성 포인트:**
  - 단순 피부 진단이 아닌 **진단 결과 → 원료 매칭 알고리즘**까지 결합
  - 화장품 제조사가 IT를 결합한 사례는 아직 청구항 차별화 여지 있음
- **벤처인증 적합도:** **4.0/5**
- **실현가능성:** **중** — 알고리즘 명세는 외부 개발사와 공동작업 가능. 핵심은 청구항 설계.
- **예상 출원 비용·기간:**
  - **약 400~500만원** (BM 특허 성격으로 청구항 작성 난이도 높음), 등록까지 **18~24개월**
- **벤처인증과의 시너지:**
  "기술융합형 사업모델" 인상을 강하게 줌. 다만 단독으로는 약하므로 No.1·2와 묶어 포트폴리오로 활용 권장.
- **주의·리스크:**
  - BM(영업방법) 특허는 거절률 높음 → **하드웨어 구성요소(측정 디바이스·서버 구조)**를 청구항에 포함시켜야 등록 가능성 상승
  - 선행기술(룰루랩·아모레 마이뷰티 등) 다수 → 차별 구성 필수

## 주제 No. 5

- **발명의 명칭(가안):** 단계별 사용 순서가 결정된 다중 앰플 화장품 키트 및 그 사용방법
  (Multi-Ampoule Cosmetic Kit Having Predetermined Sequential Usage Order and Method of Using the Same)
- **영역:** D. 사용방법·키트 특허
- **핵심 발명 요지:**
  3~4종의 앰플(예: 진정 → 보습 → 탄력 → 광채)을 **시간차(예: 7일 단위) 또는 일자별 매핑**으로 사용하도록 설계된 키트. 각 앰플은 피부의 단계적 회복 사이클(각질 → 장벽 → 진피 신호전달)에 대응하는 활성성분으로 구성.
- **권리 범위(청구항 가안):**
  "진정 활성성분을 함유한 제1 앰플, 보습 활성성분을 함유한 제2 앰플, 탄력 활성성분을 함유한 제3 앰플을 포함하며, 상기 제1, 제2, 제3 앰플을 각각 7일 간격으로 순차 사용하도록 사용 순서가 표시된 다중 앰플 화장품 키트."
- **신규성·진보성 포인트:**
  - 단순 세트 상품과 달리 **사용 순서 + 활성성분 단계별 매핑**으로 청구항 구성
  - 사용방법 청구항까지 결합 시 권리 범위 확장
- **벤처인증 적합도:** **3.7/5**
- **실현가능성:** **상** — 처방 자체는 기존 라인업 재구성으로 가능. 진입장벽 낮음.
- **예상 출원 비용·기간:**
  - **약 250~300만원**, 등록까지 **12~18개월**
- **벤처인증과의 시너지:**
  사업모델성이 강해 "제품 차별화 역량"으로 인정. 다만 다른 4건 대비 가산 강도는 낮음 → 보완용.
- **주의·리스크:**
  - 단순 키트 구성은 진보성 부정 사유 → 활성성분 + 사용 순서 + 사용 간격을 모두 한정
  - 의료기기·의약외품 영역 침범 표현(치료·개선 효능) 회피 필요

## 종합 권고

1. **포트폴리오 우선순위**: No.1(조성물) + No.2(용기) **2건 동시 출원**을 1차 권장. 약 650만원 예산으로 벤처인증 평가에서 "원천기술 + 제품화 역량" 양 축을 모두 입증 가능.
