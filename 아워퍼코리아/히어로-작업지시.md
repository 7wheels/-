# 히어로 작업지시 — 아워퍼코리아 (화장품 제조)

## 클라이언트 정보 (1차 입력)

- **회사명:** 아워퍼코리아
- **업종:** 화장품 제조
- **현재 요청:** 벤처인증을 위한 특허 5개 추천

## 의도

벤처기업 확인(벤처인증) 신청 시 "기술혁신형 벤처" 트랙에서 특허 보유는
핵심 가산점 요소. 5개 추천 → 1개 채택 → 출원 초안 작성 → 벤처인증
사업계획서 작성 흐름으로 진행.

## 1차 위임

**특허 에이전트** — 화장품 제조업 일반 컨텍스트로 벤처인증 친화적인
특허 주제 5선 추천. 추가 회사 정보가 필요하면 추천 시점에 사용자에게
질문 형태로 같이 제시.

## 후속 진행 (사용자 1개 선택 후)

1. 특허 에이전트 — 채택 주제로 국내 특허 출원 초안 작성
2. 빡빡이 — 청구항·진보성·신규성 레드팀 검증
3. 벤처인증 에이전트 — 특허 보유 시 벤처인증 11개 항목 사업계획서 작성
4. 자금/인증 에이전트 — 벤처인증 → 정책자금·R&D 과제 연계 설계

- 특허 출원 초안: `아워퍼코리아/특허-출원-초안.md` (채택 후)

## 확정 (2026-05-04)

**채택 주제: No.3** — 캡사이신·생강 동시 봉입 나노에멀젼 저온 고압 균질화 제조방법

**클라이언트 추가 정보:**
- 사업 모델: **OEM** (자체 브랜드 아님, 화장품 위탁 제조)
- R&D 인프라: **미보유** (고압 균질화기·HPLC·캡슐화 장비 자체 없음)
- 기존 특허·출원 이력: **없음** (첫 출원)
- 벤처인증 사업계획서: **보류** (특허 출원 단계까지만 진행, 벤처인증은 추후)

**No.3 작성 시 반드시 반영해야 할 제약·전략:**
1. R&D 인프라 미보유 → **외부 시험기관 위탁 시험**(KTR·KCL·한국화학융합시험연구원 등)으로 진보성 입증 데이터 확보 경로를 명세서·실시예에 반영
2. OEM 회사 → 제조사 명의로 출원 가능하나, 거래처(브랜드사)와의 권리 협의 필요성을 주의사항으로 표기
3. 첫 출원 → 청구항 폭 설계 신중히 (너무 좁으면 권리 가치 ↓, 너무 넓으면 거절 위험)
4. 화장품 카테고리 유지 (의약외품 경계 회피, 캡사이신 함량 등 명시)

**특허 에이전트 다음 작업:** 국내 특허 출원 명세서 풀세트 1회 출력
→ `아워퍼코리아/특허-출원-초안.md` 파일로 저장
→ 출력 후 빡빡이 검증 (청구항 폭·진보성·신규성·실시예 적정성)
→ 빡빡이 지적사항 보정 → 변리사 검토 가능 수준으로 마무리

**벤처인증 사업계획서 단계는 별도 보류** — 특허 출원 후 등록 진행 시점에 별도 지시 받아 진행
