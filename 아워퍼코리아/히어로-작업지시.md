# 히어로 작업지시 — 아워퍼코리아 (화장품 제조)

## 클라이언트 정보 (1차 입력)

- **회사명:** 아워퍼코리아
- **업종:** 화장품 제조
- **현재 요청:** 벤처인증을 위한 특허 5개 추천

## 의도

벤처기업 확인(벤처인증) 신청 시 "기술혁신형 벤처" 트랙에서 특허 보유는
핵심 가산점 요소. 5개 추천 → 1개 채택 → 출원 초안 작성 → 벤처인증
사업계획서 작성 흐름으로 진행.

## 1차 위임

**특허 에이전트** — 화장품 제조업 일반 컨텍스트로 벤처인증 친화적인
특허 주제 5선 추천. 추가 회사 정보가 필요하면 추천 시점에 사용자에게
질문 형태로 같이 제시.

## 후속 진행 (사용자 1개 선택 후)

1. 특허 에이전트 — 채택 주제로 국내 특허 출원 초안 작성
2. 빡빡이 — 청구항·진보성·신규성 레드팀 검증
3. 벤처인증 에이전트 — 특허 보유 시 벤처인증 11개 항목 사업계획서 작성
4. 자금/인증 에이전트 — 벤처인증 → 정책자금·R&D 과제 연계 설계
