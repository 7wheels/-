### 신청 적격 1차 검토
- 매출 8억 → 보증재단 매출 한도 내 OK
- 업력 21년 → 안정 영업·신용도 가산
- 1.5억 / 매출 8억 = 18.75% → 보증재단 평균 보증 비중 적정 범위
- 신규 제조업 추가 → "사업 다각화·혁신성" 명분 강화 / 시설자금 일부 인정 가능
- 직원 2명 채용 → **일자리 창출 가산점 항목**
- 다국가 수입 → 환율 리스크 노출, 운영자금 수요 안정성 입증 가능

## 표준 11페이지 양식 갱신 (2026-05-08)

사용자가 정책자금 사업계획서 **표준 11페이지 양식**을 명시 (올파이낸셜에셋 샘플 기준).
기존 v2.1 슬라이드 구성을 폐기하고 아래 표준으로 재작성한다.
v2.1의 빡빡이 보정 사항은 모두 유지(보수 15억 메인·자금 트랙 분리·DSCR 1.2~1.8·면책문).

### 표준 11페이지 구성

| 페이지 | 내용 |
|---|---|
| 1 | 표지 — 회사명·사업명·연락처 |
| 2 | 회사 주요 사업 소개 |
| 3 | 회사 장점·기술력 (Brand Curation·다국어·해외 트렌드 대응) |
| 4 | 주요 업적·거래처 (유럽 프랜차이즈·대형마트) |
| 5 | 대표자 경력·학력·자격증 |
| 6 | 시장 동향 + 향후 매출 예상 |
| 7 | ★ **매출 향상 계획 (1)** — 매출 구조·매출 상황·12월 매출 계획 |
| 8 | ★ **매출 향상 계획 (2)** — 매출 달성 목표 (직관적 계산식) |
| 9 | 매출 향상 근거 + 영업 인프라 |
| 10 | 자금 소요 계획 (1.5억 항목별) |
| 11 | 맺음말 (THANK YOU) |

### 절대 유지 (빡빡이 v2 보정)
- 2026 매출 **기본 15억(메인) / 공격 20억** (단정 20억 금지)
- 자금 사용처: **운영자금 1억 + 시설·창업자금 0.5억 (트랙 분리 신청)** 명기
- DSCR 1.2~1.8배 (영업이익률 7~12% 감도분석) — 단정 금지
- P11 면책문: "매출 전망은 회사 자체 추정이며 보증재단 심사 결과를 보장하지 않습니다"
