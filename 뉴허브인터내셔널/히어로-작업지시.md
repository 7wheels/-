# 히어로 작업지시 — (주)뉴허브인터내셔널 (수입유통업)

## 클라이언트 정보 (1차 입력)

- **회사명:** (주)뉴허브인터내셔널
- **업종:** 수입유통업
- **현재 요청:** 정책자금 사업계획서 작성
- **자료:** 엑셀 파일 (사용자 측 준비 완료, 위치 확인 필요)

## 1차 위임 흐름

1. 사용자에게 **엑셀 파일 위치·업로드** 요청
2. 엑셀 파일 수신 후 **사업계획서 에이전트** 위임 — 11페이지 인포그래픽
   슬라이드 형태 정책자금 사업계획서 PDF 생성
3. **빡빡이 검증** — 자금 사용 계획·매출 추정·정책자금 적격성 검증
4. 자금 에이전트 후속 조율 (필요 시)

## 산출물 저장 위치

- 엑셀 원본 (사용자 업로드): `뉴허브인터내셔널/원본자료.xlsx` (예시 경로)

- 빌드 스크립트: `뉴허브인터내셔널/generate_plan.py`

## 추가 확인 필요 정보 (사용자 답변 요청)

엑셀 자료 외 사업계획서 작성에 필요한 항목:
1. 신청 대상 정책자금 (중진공·기보·신보·소상공인·지자체 등 — 1순위 결정)
2. 자금 규모 (희망 융자·보증 금액)
3. 자금 사용 목적 (운영자금·시설자금·R&D·해외진출 등)
4. 업력·매출·임직원 수
5. 주력 수입 품목·해외 거래선
6. 신청 목표 시점

## 확정 (2026-05-07)

| 항목 | 확정 내용 |
|------|----------|
| 신청 대상 | **신용보증재단(지역 신보)** — 지역 소기업·소상공인 보증 |
| 보증 희망액 | **1억 5천만원** |
| 자금 사용처 | ① 운영자금 ② 수입결제 ③ **제조업 추가**(사업 다각화) |
| 업력 | **21년** (2005년경 설립 추정 — 안정 영업 기업) |
| 매출 (2025) | **8억원** |
| 인원 | 현행 + **2명 신규 채용 예정** (일자리 창출 가산점) |
| 거래국 | **프랑스·스페인·이탈리아** (유럽 3국) |
| 수입 품목 | **화장품·식품·전자제품** (다품목) |
| 시점 | **긴급** (1개월 내 신청 목표) |
| 엑셀 자료 | 채팅 업로드 불가 → 위 정보 기반으로 작성, 정확한 재무는 신청 시점에 회사 측 보정 |

### 신청 적격 1차 검토
- 매출 8억 → 보증재단 매출 한도 내 OK
- 업력 21년 → 안정 영업·신용도 가산
- 1.5억 / 매출 8억 = 18.75% → 보증재단 평균 보증 비중 적정 범위
- 신규 제조업 추가 → "사업 다각화·혁신성" 명분 강화 / 시설자금 일부 인정 가능
- 직원 2명 채용 → **일자리 창출 가산점 항목**
- 다국가 수입 → 환율 리스크 노출, 운영자금 수요 안정성 입증 가능
