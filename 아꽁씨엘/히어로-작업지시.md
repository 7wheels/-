## 사업 스토리 (히어로 판단)

### 핵심 가치 제안
"명품 브랜드 폐원단을 등급별 재생·재조합하여 **업사이클 프리미엄 원단**을 제조·유통.
유럽 원단 독점 채널 + 특허 기반 재생 공정으로 **ESG·순환경제 프리미엄 원단** 시장을 개척."

### 5대 강점
1. **친환경·ESG 스토리** — 명품 폐원단 재생, 지속가능 패션 트렌드 정면 부합
2. **특허 2건 출원** — 재생 분류·재조합 제조 + 업사이클 복합시트 (특허법 §16의2 벤처 가산)
3. **기업부설연구소 + 벤처인증(혁신성장)** — 정책자금 심사 가산 요소 이미 보유
4. **대표 이력** — 세인트마틴 + 루이비통 컴피티션 우승 = 브랜딩·마케팅 파워
5. **유럽 원단 독점 유통** — 인맥 기반 진입 장벽 확보

### 우려·리스크
- **매출 절대 규모 작음** — ’25년 7,000만 대비 정책자금 한도가 낮게 잡힐 수 있음
- **재고 회전 리스크** — 원단 유통·제조 특성상 자금 회전 압박
- **영업이익률·재무 상태** 미확인

3. **자금 사용 목적** — 운영자금 / 시설자금(자체 재생 라인 구축 등) / R&D / 재고 자금 / 마케팅
4. **신청 목표 시점** — 긴급(1개월) / 분기 내 / 연간 계획

### B. 대표·법인 확정 정보

### D. 인력·설비
