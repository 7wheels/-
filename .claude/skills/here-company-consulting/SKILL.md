# 히어컴퍼니 기업컨설팅 하네스

기업의 성장 단계에 맞춘 맞춤형 통합 컨설팅. S-OJT 기반 인력개발부터 정책자금·인증·법인전환·스케일업 전략과 대표 마인드셋까지 기업 성장의 전 과정을 지원한다.

## 히어컴퍼니 핵심 철학

**"기업과 대표가 함께 성장한다"**

외부 환경(정책, 시장)을 최대한 활용하면서, 내부 역량(인력, 시스템, 대표 마인드)을 동시에 강화한다. 단기 처방이 아닌 지속 가능한 성장 구조를 만든다.

## 6대 서비스 + 1 체계

```
┌─────────────────────────────────┐
│     기업스케일업 전략 (중심축)      │
├──────────┬──────────┬───────────┤
│  S-OJT   │ 기업인증  │  정책자금  │
│ 인력개발  │ (벤처·이노 │ 융자·보증 │
│         │  비즈 등) │  투자유치  │
├──────────┴──────────┴───────────┤
│      법인설립·전환 (기반 구조)     │
├─────────────────────────────────┤
│     대표 마인드셋 (성장 엔진)      │
└─────────────────────────────────┘
```

## 에이전트 팀 구성

```
here-company-orchestrator (총괄 감독)
├── scaleup-strategist (스케일업 전략 중심)
├── ojt-specialist (S-OJT·인력개발)
├── certification-expert (기업인증)
├── policy-fund-expert (정책자금·자금확보)
├── legal-corporate-expert (법인설립·전환)
└── ceo-mindset-coach (대표 마인드셋)
```

패턴: **Expert Pool + Supervisor**

## 기업 단계별 컨설팅 패키지

### 예비창업·초기창업 (업력 3년 이하)
- 법인설립 또는 전환 검토
- 창업 지원사업 발굴 (정책자금)
- 기업부설연구소 설립 타이밍 검토
- 대표 창업가 마인드셋 코칭

### 성장기 기업 (매출 10~50억)
- S-OJT 기반 체계적 인력개발
- 벤처·이노비즈 인증 취득
- 중진공·기보 정책자금 활용
- 기업스케일업 전략 수립

### 스케일업 단계 (매출 50억+)
- 투자유치 전략 (VC, 엔젤)
- 코스닥 상장 준비 로드맵
- 조직 시스템화 및 후계자 육성
- 대표 리더십 전환 코칭

## 실행 흐름

1. **진단** — here-company-orchestrator가 기업 현황 분석
2. **라우팅** — 필요한 전문가 에이전트 소집 (Expert Pool)
3. **병렬 분석** — 각 전문가가 담당 영역 심층 분석
4. **시너지 설계** — 서비스 간 연계 효과 극대화
5. **통합 리포트** — 우선순위·로드맵·기대효과 통합

## 주요 산출물

**진단 산출물:**
- 기업 현황 진단 보고서
- 성장 단계 및 과제 매핑

**전략 산출물:**
- 기업스케일업 로드맵 (1·3·5년)
- 자금 조달 포트폴리오 설계
- 인증 취득 로드맵

**실행 산출물:**
- 정책자금 신청 준비 체크리스트
- S-OJT 훈련 계획서
- 법인전환 타당성 분석

## 품질 기준

- 실행 가능성: 당장 다음 달부터 실행할 수 있는 구체적 행동 제시
- 연계 효과: 각 서비스가 다른 서비스에 미치는 긍정적 영향 설계
- 맞춤화: 기업의 업종·규모·단계에 최적화
- ROI 명시: 컨설팅 비용 대비 기대 효과 수치화
