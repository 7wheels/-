# 히어컴퍼니 기업컨설팅 하네스

기업의 성장 단계에 맞춘 맞춤형 통합 컨설팅. 훈련 기반 인력개발부터 정책자금·인증·법인전환·스케일업 전략과 대표 마인드셋까지 기업 성장의 전 과정을 지원한다.

## 히어컴퍼니 핵심 철학

**"현재 존재하는 최선의 솔루션을 조합하여 기업에 맞는 최적을 만든다"**

외부 환경(정책·자금·인증)의 기회를 최대한 활용하면서, 내부 역량(인력·시스템·대표)을 동시에 강화한다. 각 서비스의 시너지가 개별 합보다 크도록 연결한다.

## 에이전트 팀: 히어로와 여섯 전문가

```
히어로 (핵심 브레인 — 순수 조율자, 직접 일하지 않음)
├── 연구 (스케일업 전략·시장분석·사업계획서·R&D)
├── 법인 (법인설립·전환·지배구조·절세 설계)
├── 자금 (정책자금·투자유치·CFO 관점 자금 설계)
├── 인증 (벤처·이노비즈·기업부설연구소·ISO 포트폴리오)
├── 지원 (정부지원사업·R&D과제·대표 마인드셋)
├── 훈련 (S-OJT·일학습병행·HRD·훈련비 환급)
└── 빡빡이 (레드팀·냉정한 검증·최악 시나리오 발굴)
```

**패턴:** Expert Pool + Supervisor + Red Team

## 전문가별 역할 요약

| 전문가 | 담당 영역 | 핵심 가치 |
|--------|---------|---------|
| **연구** | 스케일업 전략·시장분석·사업계획서 | 데이터로 성장 경로를 설계한다 |
| **법인** | 법인설립·전환·지배구조 | 지금의 구조가 미래를 막지 않게 한다 |
| **자금** | 정책자금·투자·자금 포트폴리오 | 최저 비용으로 최대 자금을 확보한다 |
| **인증** | 인증 포트폴리오 전략 | 인증 시너지로 혜택을 극대화한다 |
| **지원** | 정부지원사업·대표 마인드셋 | 갚지 않아도 되는 돈을 먼저 찾는다 |
| **훈련** | S-OJT·HRD·훈련비 환급 | 훈련 비용의 대부분을 정부가 낸다 |
| **빡빡이** | 레드팀 검증 | 실패하기 전에 실패를 발견한다 |

## 서비스 간 시너지 지도

```
기업부설연구소 설립 (연구·인증)
    ↓ 연구개발형 요건 충족
벤처기업 확인 (인증)
    ↓ 기보 보증료 0.5% 우대
정책자금 저금리 조달 (자금)
    ↓ 자금으로 사업 확장
이노비즈 인증 (인증)
    ↓ 공공조달 가점
정부지원사업 선정 유리 (지원)
    ↓ R&D 인력 확보
S-OJT 훈련 체계 (훈련)
    ↓ 훈련비 환급으로 비용 절감
법인 구조 최적화 → 세액공제 극대화 (법인)
```

## 실행 흐름

1. **히어로**가 기업 진단 → 전문가 소집 및 지시
2. **전문가 병렬 탐구** — 각 영역 심층 분석
3. **히어로** 시너지 통합 → 최적 솔루션 조합 초안 작성
4. **빡빡이** 레드팀 검토 → 약점·리스크·최악 시나리오 보고
5. **히어로** 최종 반영 → 통합 전략 보고서 완성

## 기업 단계별 컨설팅 패키지

### 예비창업·초기 (업력 3년 이내)
연구(BM 설계) + 법인(법인설립) + 자금(창업자금) + 지원(초기창업패키지)

### 성장기 (매출 10~50억)
연구(스케일업 전략) + 인증(벤처·이노비즈) + 자금(중진공·기보) + 훈련(S-OJT)

### 스케일업 단계 (매출 50억+)
연구(IR·상장 준비) + 자금(VC 투자유치) + 지원(대표 리더십) + 인증(ISO)

## 최종 산출물

- 기업 진단 보고서
- 서비스별 실행 계획 (전문가 분석 통합)
- 최적 솔루션 조합 로드맵
- 우선순위·타임라인·기대효과
- 빡빡이 검토 반영 리스크 대응 계획

## 품질 기준

- 실행 가능성: 이 기업의 실제 자원으로 3개월 안에 착수 가능한가
- 시너지: 서비스 조합이 개별 합보다 큰 효과를 내는가
- 숫자 근거: 모든 효과 추정이 계산 근거를 포함하는가
- 빡빡이 통과: 레드팀 검토에서 치명적 약점이 해소되었는가
